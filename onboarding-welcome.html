Design Specs

Summary

Welcome landing page for newly enrolled partners showing account confirmation, 90-day onboarding checklist with progress tracking, quick access to authenticated portal features, and downloadable program documents.

Jobs to Be Done

  • Display partner account details and enrollment confirmation
  • Show first 90-day onboarding checklist with completion tracking via localStorage
  • Provide deep links to authenticated portal pages (rep-home, rep-register-deal, rep-course-catalog, rep-pipeline, rep-sales-tools, rep-deals-commission)
  • Enable document downloads for partnership agreement, program guide, commission schedule, and code of conduct
  • Track checklist progress and encourage completion of required items within 30 days
  • Display partner tier, Channel Manager info, and commission rate

Design Specification

Primary Content

  • Welcome hero section with completion badge and call-to-action
  • Auto-generated welcome email mockup with Partner Central credentials and login instructions
  • Partner account details card displaying Partner ID, company name, tier, and manager
  • Getting Started 90-day checklist with 6 action items and required/recommended tags
  • Quick Links grid with 6 portal shortcuts to common workflows
  • Your Documents section with 4 downloadable files: Partner Agreement, Program Guide, Commission Schedule, Code of Conduct

Interactive Elements

  • Hero CTA button to log in to Partner Central with authentication redirect
  • Email mockup with credentials box and copy-to-clipboard functionality
  • Checklist items with checkbox controls persisted via localStorage and required/recommended/time tags
  • Quick Links cards with icons and deep links to partner portal pages
  • Document rows with file icons, metadata (size, type), and download links
  • All-complete step indicator showing 5 of 5 onboarding steps finished

Functionality

  • Checklist Management & Persistence
    • localStorage-based checklist persistence tracking completion state across sessions via JSON serialization storing checklist_state object with keys for each task (setup_sso, download_guides, schedule_training, configure_api, assign_users)
    • Checkbox event listeners on each checklist item calling localStorage.setItem('partner_checklist', JSON.stringify(state)) on change to persist checkbox.checked state
    • Page load initialization retrieving localStorage data with JSON.parse() and restoring checkbox states preventing duplicated work on repeat visits
  • Data Integration & Auto-Population
    • Auto-populated account details from Partner__c lookup fields via Visualforce page server-side controller querying Partner__c record using URL parameter ?partnerId={!$CurrentPage.parameters.partnerId}
    • Apex controller binding Partner_ID__c, Company_Name__c, Tier__c, Territory__c, and Enrollment_Date__c field values to public properties merged into page component HTML
    • Channel Manager display pulling Partner__c.Channel_Manager__r.Name and Channel_Manager__r.Phone__c related lookup values from Account record
  • Email Archival & User Provisioning
    • Server-side email archive triggered by after-insert Apex trigger on Partner__c record creating welcome email and storing in EmailMessage object with email template merge fields
    • User enrollment provisioning executing Apex method Partner_PortalAccessProvisioner.createPartnerUser() creating new User record with Profile = 'PCP Partner Rep' and linked to Partner__c
    • Username generation using Company_ID__c + '_admin' pattern stored as unique constraint on User.Username field with initial password sent via Messaging.sendEmail()
  • Document Management & Downloads
    • Document download URLs generated from Agreement__c attachment records via SOQL query selecting Attachment objects WHERE ParentId = Partner_Agreement__c.Id
    • Download link construction returning /servlet/servlet.FileDownload?file={!AttachmentId} URL pattern for direct file access with file name and size metadata displayed
    • Program template documents (Program Guide, Commission Schedule, Code of Conduct) linked from Document object stored in Salesforce files with download links built from ContentDocument.LatestPublishedVersion.Id
  • Portal Navigation & Access Control
    • Deep-link routing to authenticated portal via JavaScript redirect to /s/partner-central with SessionID validation token passed as URL parameter requiring server-side token validation
    • Role-based access control enforced via User Profile query on authenticated session User.Profile.Name verifying 'PCP Partner Rep' profile before displaying partner portal navigation
    • Session verification executing apex method sessionVerify() on page load checking session.getSessionId() against OAuth token whitelist before rendering sensitive content

Technical Details

Key Objects

  • Partner__c (Partner_ID__c, Tier__c, Territory__c, Enrollment_Date__c, Agreement__c lookup, Channel_Manager__c)
  • User (Profile = 'PCP Partner Rep', related to Partner__c via Account)
  • Document — Stored files: Agreement PDF, Program Guide, Commission Schedule, Code of Conduct
