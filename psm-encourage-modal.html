Design Specs

Summary

Guided workflow for PSM to compose and send personalized encouragement messages to partners approaching tier advancement, with template options, tone selection, and activity logging.

Jobs to Be Done

  • Send targeted encouragement messages to partners approaching tier advancement
  • Highlight specific benefits unlocking at next tier to motivate progression
  • Allow personalization of message tone and custom notes for relationship building
  • Track communication history for relationship management and compliance
  • Schedule deferred sending for optimal timing with partner

Design Specification

Primary Content

  • Account Contact Manager card displaying Manager Name, Email
  • Tier Progress Snapshot showing current tier, next tier goal
  • Gold Tier Benefits Unlock card listing 5 benefits: Commission Rate Increase
  • Message Tone selector with 3 radio options: "Almost there!", "Quick update"
  • Personal Note field as optional textarea for customization
  • Email Preview card showing how the message will appear to the partner
  • Recent Encouragement History section with 3 previous messages sent

Interactive Elements

  • Select tone radio buttons
  • Text input field for Personal Note
  • "Preview" button to display how email will render
  • "Send & Log Activity" button to send communication immediately
  • "Schedule Send" option to defer delivery to specific date/time
  • Expandable previous message history for reference
  • "Cancel" to close modal without sending

Functionality

  • Data Retrieval & Partner Profile
    • Query Account and Account_Partner_Tier__c records to fetch contact name, email, and tier information
    • Display current tier status (Silver, Gold, Platinum) with progress score and milestone target points
    • Render previous tier progression history from Partner_Communication_History__c records
  • Tier Progress Calculation
    • Calculate tier progress points from Partner_Tier_Score__c using weighted formula (deal volume, revenue, engagement metrics)
    • Determine next milestone requirements and points gap to advancement
    • Fetch tier benefit details from Tier_Benefit__c object for display in message context
  • Message Template & Tone Selection
    • Generate template message body based on selected tone option (Almost there!, Quick update, Let's chat) using message template records
    • Merge contact name, current/next tier, benefits list, and personal notes into email template
    • Render live email preview showing how message will appear to recipient with formatting
  • Activity Logging & Communication History
    • Log outbound email to AccountContactRelationship as activity record with tone metadata
    • Query Partner_Communication_History__c to display previous encouragement messages sent to contact
    • Track message open/click events via EmailOpen object for engagement analytics
  • Send & Scheduling
    • Trigger async send via MailMerge action on account record or schedule delivery with datetime field
    • Update last_encouragement_sent__c timestamp and increment communication_count__c on Account record
