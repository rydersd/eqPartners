Design Specs

Summary

First-login onboarding wizard for new partner reps with multi-step guided tour covering security setup, profile completion, feature overview, and assigned training. Steps progress through MFA enrollment, profile customization, portal navigation, and initial training assignments.

Jobs to Be Done

  • Guide new partners through portal features
  • Collect initial profile and setup information
  • Highlight key functionality for first use
  • Set expectations for portal capabilities
  • Provide quick access to help and support
  • Enable smooth transition to portal home

Design Specification

Primary Content

  • Welcome headline with partner rep name and portal introduction
  • Step indicator bar (visual progress: 1-4 steps, showing current step)
  • Step 1: MFA Setup — Multi-factor authentication enrollment instructions with authenticator app steps
  • Step 2: Profile Completion — Form fields for name, email, title, department, phone
  • Step 3: Portal Features — Feature overview cards (Training, Deals, Resources, Certifications)
  • Step 4: Assigned Training — List of required and recommended courses from Training_Assignment__c
  • Next/Previous buttons for step navigation
  • Skip This Step and Complete Onboarding action buttons

Interactive Elements

  • Next/Previous buttons for step navigation
  • Form input fields for profile data (name, email, title, etc.)
  • Checkbox inputs for authenticator app confirmation steps
  • Skip This Step link on optional steps
  • Complete Onboarding button (final step)
  • Feature cards with icons and descriptions
  • Training course list with start/view buttons

Functionality

  • First-Login Detection & Wizard State
    • First-login detection via User.IsFirstLogin__c flag set by provisioning flow on account creation; portal landing page checks this flag and routes to onboarding wizard
    • Multi-step wizard progression stored in session state; steps fetched from Onboarding_Step__c and ordered by Step_Order__c
    • Current step displayed dynamically; Next/Skip buttons update session and load subsequent step
  • MFA Setup & Authentication
    • Step 1 (Multi-Factor Auth): Triggers Salesforce Identity MFA enrollment flow via API callout or embedded Salesforce Identity component
    • MFA completion status stored in User.MFA_Verified__c; verified users bypass MFA setup on future logins
    • QR code and backup codes displayed for authenticator app setup
  • Profile Completion & Preferences
    • Step 2 (Complete Profile): Form inputs update Contact fields (Title, Phone, Department, Company) and User.Preferred_Name__c via form submit
    • Form validation checks required fields (Email from User object, Title from Contact); shows validation errors inline if missing
    • Save Profile triggers UPDATE Contact and User records; Next button enabled after successful save
  • Feature Discovery & Training Assignments
    • Step 3 (Discover Features): Static content with feature cards fetched from Portal_Feature__mdt custom metadata; cards include Feature_Name__c, Description__c, Icon_URL__c, Display_Order__c
    • Step 4 (Assigned Training): Queries Training_Assignment__c WHERE Contact__c=[logged-in user] WITH linked Course details; displays Status, Due_Date__c, and Start Course links
    • Training cards sorted by Due_Date__c (soonest first); course links navigate to course detail pages
  • Completion & Routing
    • Skip Step link sets Onboarding_Step__c.Skipped__c=true; Next button marks current step as Completed__c=true and advances to next step
    • Complete Onboarding button (final step): updates User.IsFirstLogin__c=false, Onboarding_Checklist__c.Status='Complete', then redirects to home page
    • Provisioning flow triggers on completion: sends welcome email, creates initial audit log entry, syncs Contact to external systems

Technical Details

Salesforce Objects & Flow

  • User object: IsFirstLogin__c (boolean), MFA_Verified__c (checkbox), Preferred_Name__c (text)
  • Onboarding_Step__c custom object (junction to User): Step_Order__c, Step_Name__c, Completed__c (checkbox), Skipped__c (checkbox)
  • Onboarding_Checklist__c custom object: User__c (lookup), Status__c (In Progress|Complete), Completion_Date__c
  • Training_Assignment__c: Contact__c, Course__c (lookup), Status__c, Due_Date__c
  • Portal_Feature__mdt: Feature_Name__c, Description__c, Icon_URL__c, Link__c, Display_Order__c
  • On complete onboarding: Provisioning flow updates Contact sync, sends welcome email, creates initial audit log entry
