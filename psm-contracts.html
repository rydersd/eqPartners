Design Specs

Summary

Centralized contract management system for PSMs to store, version, manage e-signature workflows, track expiration, and maintain amendment history for all partner agreements. Stark Industries Gold tier agreement renewed Jan 15, 2026, with Pepper Potts (COO) as signatory and Marcus Chen as Equinix contact.

Jobs to Be Done

  • Centralize contract repository for all partner agreements with version control
  • Track agreement lifecycle from creation through renewal with status indicators
  • Manage e-signature workflows with templated sending and status tracking
  • Monitor contract expiration dates and automate renewal alerts
  • Maintain audit trail of all amendments and modifications to agreements

Design Specification

Primary Content

  • Four KPI cards showing Active Agreements count, Expiring in 90 Days, Pending E-Signature, Renewal Alerts
  • Active agreements table with partner name, contract type, status, effective date, expiry date
  • E-signature tracker showing workflow stages (Sent, Viewed, Signed, Countersigned, Executed)
  • Amendment history section tracking changes to agreements with date, type, and user
  • Template management table with contract templates, version, created date, and last used
  • Expiration alert banner highlighting agreements expiring within 90 days

Interactive Elements

  • New Agreement button to initiate contract creation from templates
  • View Details links on each agreement row for drilling into full contract view
  • Send for E-Signature button to initiate DocuSign/signature workflow
  • View Amendment History links to access full change log for each agreement
  • Template Management section with add new template, edit, delete, and duplicate actions
  • Filter controls by agreement type, status, expiration date range
  • Sort controls by effective date, expiry date, or status

Functionality

  • Contract Retrieval & Versioning
    • Query Contract__c records linked to Account and retrieve version history for comparison
    • Support versioning by creating new Contract__c version record on amendment
    • Display amendment history tracking changes, dates, and users who made modifications
  • Expiration Tracking & Alerts
    • Calculate days-to-expiration and flag agreements expiring within 90 days with alert banner
    • Create renewal alerts via workflow rule when Expiry_Date__c < TODAY() + 90
    • Auto-generate renewal notifications at 90, 60, and 30 days before expiry via scheduled action
  • Amendment Management & Change Tracking
    • Auto-create Amendment__c records when Contract__c fields are updated with reason captured
    • Enforce amendment creation requires change reason and authorized PSM approval
    • Track all changes to Contract__c in field history for audit compliance and transparency
  • E-Signature Integration & Workflow
    • Integrate DocuSign/e-signature platform via API for Send, Track, and Retrieve workflows
    • Update E_Signature_Status__c field based on webhook callbacks from signature platform
    • Display e-signature tracker showing workflow stages (Sent, Viewed, Signed, Countersigned, Executed)
    • Validate signer email addresses before initiating e-signature request

Technical Details

Validation & Business Logic

  • Contract creation requires Account, Contract Type, and Template selection
  • E-signature requires valid signer email addresses
  • Amendment creation requires change reason and authorized PSM approval
  • Renewal alerts auto-generated 90, 60, 30 days before expiry via scheduled action
  • Field history tracking enabled on Contract__c for audit trail
