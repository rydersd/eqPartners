Purpose

PSM reviews incoming partner organization applications. Validates company identity, monitors compliance screening and document completeness, and either approves, requests additional information, or declines the application.

Functionality

Application Intake
  • Applications are automatically assigned to PSM based on applicant's primary address territory (US West → Marcus Chen). Auto-initiates OFAC screening and sends DocuSign MPA + T&C envelope upon submission.
  • PSM receives email notification with application summary and link to this review page.
Document Tracking
  • Checklist tracks all required documents with real-time status. PSM can trigger DocuSign resends for unsigned envelopes.
  • W-9 documents are queued for manual PSM review to validate entity name and EIN match the Salesforce record.
Compliance Checks
  • OFAC screening, business registry validation, and domain verification run automatically in parallel. Results appear in the document checklist within 24 hours.
  • Approve button is gated: all required docs must be complete and all compliance checks must pass before PSM can approve.
Approval Gate
  • On approval: Salesforce Account record is created, portal access provisioned (PM + Technical Contact), SumTotal training accounts activated, welcome email sent to PM, kickoff task created for PSM.
  • Declined applications trigger a notification email to the applicant explaining the reason.

Key Concepts

  • Application ID · Auto-territory assignment · Document completeness gate · Compliance screening · Approval triggers
