Design Specs

Summary

The Partner Manager Home Dashboard provides Pepper Potts (COO, Stark Industries) with a personalized landing page showing Gold tier status, $180K portfolio MRR, 5 active deals worth $197K pipeline, 95% team training completion, and quick access to priority workflows. Stark Industries has 9 team members with strong sales leadership (Tony Stark 100%, James Rhodes 88%, Bruce Banner 83%), active co-sell with PSM Marcus Chen, and an alert for Sarah Connor's expired cert.

Jobs to Be Done

  • See personalized welcome and org status at a glance
  • Monitor tier progress and understand required steps for tier maintenance
  • Track key metrics: team training %, deals, active opportunities, MDF budget
  • View top-priority opportunities and team alerts needing action
  • Access most common workflows (assign course, register deal, view training) from one page
  • Stay informed of program announcements and deadlines
  • Understand team training progress and individual member performance

⚡ Day N — Experience Cloud Design Notes

This is the Day N (returning admin) experience. The companion page pm-home-day0.html covers Day 0 for a new Portal Admin. Key EC differences on Day N:

  • Admin Getting Started checklist hidden — Audience rule: checklist component visible only when Contact.Admin_GS_Complete__c = false. On Day N, all 4 items are done and the component fully hides.
  • Welcome banner: "Welcome back" — Copy condition: if Contact.First_Login__c was more than 7 days ago, greeting is "Welcome back, [Name]." On Day 0: "Welcome to Partner Central, [Name]."
  • Pending requests: compact widget, not hero card — On Day 0, the pending requests card dominates the left column (red border, banner callout). On Day N, it's a compact announcement-style item that appears in the Announcements card only when pending count > 0 (PartnerUserRequest__c WHERE Status='Pending' AND AccountId=User.AccountId).
  • Team section shows live data — Day 0 shows the empty-state team grid. Day N shows the full team training snapshot table (member, completion %, status) and KPI mini-cards (Team Training %, Active Deals, etc.). Same component; empty state is a fallback view when record count = 0.
  • Programs: sidebar widget — On Day 0, programs get a full card to orient the new admin. On Day N, programs move to a compact right-column sidebar widget. Admin already knows their programs at this point; widget stays visible for quick renewal-date monitoring.
  • Day N IAG prompts — Different In-App Guidance library. Day N prompts fire on specific data conditions: "Sarah Connor's cert expired — this blocks her deal eligibility" (fires when team has expired cert), "Fabric Referral renewal is in 30 days — contact your PSM" (fires 30 days before renewal), "Your team is 2 courses from Gold maintenance" (fires when within threshold). All targeted by Audience rules; dismissed once resolved.
  • Activity feed is live — Day N shows Team Activity (training completions, deal registrations, cert awards). Day 0 has no activity data to show (team just joined). Same component; empty state returns default "No activity yet" copy.

Design Specification

Primary Content

  • Welcome banner with org name and current tier badge
  • Tier Progress card with status, progress bar, and next tier preview
  • KPI cards: Team Training %, Active Deals, Pending Approvals, Total MRR
  • Active Opportunities table with pipeline stage and close date
  • Team Training Progress with org-wide completion rate and member snapshot table
  • Personal Training Progress stats
  • Quick Actions grid linking to common workflows
  • Announcements list with program updates and deadlines
  • PSM message card with encouragement and next steps
  • Team Activity feed showing recent training, deals, approvals

Interactive Elements

  • Click Tier Progress card to see detailed tier requirements and benefits
  • Click Active Opportunities table rows to view opportunity details and links
  • Quick Action buttons navigate to respective pages (Assign Course, Register Deal, etc.)
  • View All links in announcements and activity feed sections
  • Announcement items are clickable to expand and view full content
  • Activity feed items link to corresponding training, deal, or approval records

Functionality

  • Access Control & Permissions
    • Role-based access control enforces PM permission set requirement to view team-wide data
    • PSM assignment validation with fallback messaging if assignment is missing
  • Calculation & Aggregation
    • Tier progress calculation engine: completed_requirements / total_requirements with dynamic progress display
    • Aggregate KPI queries with 5-minute caching for optimal performance
  • Data Display & Integration
    • Metadata-driven tier benefits display using Tier_Benefits__mdt lookups for dynamic content
    • Real-time activity feed aggregation from training, deal, and opportunity objects with timestamp sorting

Technical Details

Validation & Business Logic

  • Only users with PM permission set see team data across account
  • Tier benefit preview pulls dynamically from Tier_Benefits__mdt metadata
  • KPIs refresh on page load from cached aggregate query (5-min cache)
  • PSM assignment required; if null, show "Contact PSM for support"
  • Tier progress percentage calculated as: completed_requirements / total_requirements
