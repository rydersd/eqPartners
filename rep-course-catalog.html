Validation Rules & Edge Cases

Enroll creates Partner_Training__c with Status='Not Started' — Click "Enroll" triggers Salesforce record insert via flow: Partner_Training__c.create(Contact__c=LoggedInUser.Contact, Course__c=[selected], Status__c='Not Started', Enrollment_Date__c=TODAY()). SumTotal_Enrollment_Flow also triggered to sync with LMS.

Cannot enroll in course if prerequisite incomplete — Flow validation: If Course__c.Prerequisites__c is not blank, query Partner_Training__c where Contact=LoggedInUser AND Course__c=[prerequisite] AND Status__c='Completed'. If no result, show error toast: "Complete [prerequisite course name] first".

Max 5 concurrent in-progress courses — Validation rule: COUNT(Partner_Training__c where Contact=LoggedInUser AND Status__c='In Progress') <= 5 OR ERROR "Maximum 5 active courses. Complete one to start another.".

Featured "Required" courses highlighted on catalog — Courses in Tier_Course_Requirement__mdt for logged-in Account.Partner_Tier__c are fetched and displayed in "Required for Your Tier" section at top. Card gets featured class (blue border, prominent styling).

Design Specs

Summary

Displays searchable and filterable catalog of training courses organized by track, category, and tier requirements. Shows required courses prominently and tracks enrollment status for each course.

Jobs to Be Done

  • Browse all available training courses
  • Discover courses by category or level
  • See course status and enrollment eligibility
  • Find courses relevant to role or tier
  • Compare courses before enrolling
  • Enroll in new training quickly

Design Specification

Primary Content

  • Section "Required for Gold Tier" with 4 featured required courses
  • Section "All Courses" with grid of 12 displayed course cards (32 available)
  • Course cards: icon, title, description, track badge (Business/Technical), level badge, duration, status indicator (Not Started/In Progress/Completed/Required)
  • Sidebar filters for Track, Category (Intro, Sales, Colocation, Interconnection), Level (Beginner, Intermediate, Advanced), Duration (Under 1hr, 1-3hr, 3+hr)
  • Search bar with real-time filtering
  • My Plan sidebar showing 4 assigned courses, 6 completed courses
  • Activity tab showing recent enrollments and completions
  • Agentforce AI recommendation tab suggesting next courses

Interactive Elements

  • Search bar with keyword filtering
  • Checkbox filters for Track, Category, Level, Duration with course counts
  • Clear All Filters link
  • Enroll button (creates Partner_Training__c enrollment)
  • Resume button for in-progress courses (redirect to SumTotal LMS)
  • Completed button (disabled state) for finished courses
  • Start Next Course and View Training action buttons in right rail

Functionality

  • Catalog Loading & Display
    • Course__c objects queried with Track__c, Category__c, Level__c, Duration__c, Is_Required__c, Has_Certification__c fields; grid displays by default in 3-column layout (responsive to 2-column on smaller screens)
    • Tier_Course_Requirement__mdt custom metadata type determines which courses display in "Required for Your Tier" section based on logged-in Account.Partner_Tier__c (Bronze|Silver|Gold)
    • Featured courses with blue borders and prominent styling are pulled from tier requirements and shown first
  • Enrollment & Validation
    • Enroll button creates Partner_Training__c record with Contact__c=LoggedInUser.Contact, Course__c=[selected], Status__c='Not Started', Enrollment_Date__c=TODAY()
    • Frontend validation checks Course__c.Prerequisites__c; if not blank, queries Partner_Training__c WHERE Contact=LoggedInUser AND Course__c=[prerequisite] AND Status__c='Completed'; shows error toast if incomplete: "Complete [course name] first"
    • Validation rule enforces max 5 concurrent in-progress courses: COUNT(Partner_Training__c where Contact=LoggedInUser AND Status__c='In Progress') ≤ 5
  • Status Tracking & User State
    • Course status displayed from Partner_Training__c.Status__c enum (Not Started, In Progress, Completed); status badges update after enrollment or LMS completion syncs
    • Enroll/Resume/Completed buttons dynamically rendered based on Partner_Training__c records for logged-in user
    • Search and filter sidebar selections persisted in session; filtered course count displayed dynamically
  • LMS Integration & SSO
    • Start Course/Resume buttons generate JWT SSO token and redirect to SumTotal LMS with Contact.Email + Course.SumTotal_Course_ID__c parameters
    • SumTotal_Enrollment_Flow (scheduled) syncs Partner_Training__c.Status__c to LMS after record creation via API callout
    • Completion callback from LMS updates Partner_Training__c.Status__c='Completed', Score__c, Completion_Date__c=TODAY()

Technical Details

Salesforce Objects & Sync

  • Course__c custom object with fields: Course_Name__c, Track__c, Category__c, Duration__c (hours), Level__c, Description__c, Prerequisites__c, SumTotal_Course_ID__c (external ID), Has_Certification__c, Is_Required__c
  • Tier_Course_Requirement__mdt custom metadata type defining required courses per Partner_Tier__c (Bronze|Silver|Gold)
  • Partner_Training__c object stores enrollments with Enrollment_Date__c, Status__c, Completion_Date__c, Score__c
  • SumTotal_Enrollment_Flow (scheduled flow) syncs Partner_Training__c records to SumTotal LMS via API call with Contact.Email + Course.SumTotal_Course_ID__c
