My Profile — Sales Rep

Trigger

This page is reached by clicking the user avatar in the top-right of the Partner Portal navigation bar. The avatar shows the user's initials and carries the partner-employee color (violet). An aria-current="page" attribute marks it as active when on this page.

Design Notes

  • Avatar initials are derived from First Name + Last Name (first character each)
  • Certification status is read-only; the "View all" link navigates to rep-certifications.html
  • Notification toggles should persist via user preference API calls
  • Security section should never display the actual password; "Change" launches a modal flow
  • Recent Activity pulls from audit/activity log; limit to 4 most recent on this summary view

Fields

Personal info fields are editable inline or via Edit modal. Company & Role section is read-only (managed by Portal Admin). PSM is assigned by Equinix and is not user-editable.
