Design Notes

Summary

Partners submit actual campaign performance metrics and supporting documentation to complete MDF reimbursement claims. Compares planned vs. actual results and tracks submission status through approval and payment.

Jobs to Be Done

  • Submit proof that MDF-funded activities were completed
  • Provide documentation for reimbursement processing
  • Track campaign results against original goals
  • Ensure all required evidence is included
  • Monitor reimbursement status after submission

Design Specification

Primary Content

  • Proof of Performance submission form with campaign selection
  • Reimbursement timeline and processing expectations
  • Actual spend breakdown by category with calculated totals
  • Planned vs. Actual performance comparison with variance indicators
  • Metrics form (Leads, Impressions, Attendees, Registrations)
  • Supporting documentation upload area (receipts, invoices, analytics, photos)
  • Previous PoP submissions table showing status history

Interactive Elements

  • Select approved MDF campaign from dropdown
  • Enter actual spend amounts in breakdown row fields
  • View auto-calculated totals and variance comparisons
  • Upload multiple supporting document files
  • Submit for Review or Save as Draft button actions
  • View submission status and approval history

Functionality

  • Data Retrieval & Display
    • Query approved MDF_Request__c records and populate campaign dropdown with eligible campaigns
    • Retrieve planned metrics from linked MDF_Request__c record and display in comparison grid
    • Load previous PoP_Submission__c records with submission history and reimbursement status
  • Calculation & Variance
    • Calculate total actual spend from breakdown row inputs in real-time as user enters values
    • Compute variance between planned and actual metrics (leads, impressions, registrations, attendees)
    • Display variance indicators (✓ positive, ⚠ negative) based on achievement percentage
  • Submission & Routing
    • Create POP_Submission__c record with campaign reference and actual metrics on form submit
    • Attach uploaded ContentDocument objects to submission record for file storage and tracking
    • Route submission to approver via workflow rules based on campaign amount threshold
  • Status & Workflow
    • Track submission status (Draft, Under Review, Approved, Paid) in status field with workflow state changes
    • Auto-trigger reimbursement workflow on approval status change to initiate payment processing
    • Display reimbursement timeline and processing expectations (5-7 business days)
