Design Specs

Summary

Product keyword search results for Fabric product queries, prioritizing training content and deal pipeline information to help partners learn about and sell Equinix products.

Jobs to Be Done

  • Find Fabric product training courses quickly
  • Locate battle cards and pricing guides for Fabric
  • See related Fabric deals and opportunities
  • Find reference customers for Fabric products
  • Discover related products and services
  • Check Fabric-related commission opportunities

Design Specification

Primary Content

  • Synonym expansion banner showing "Fabric" alternatives
  • Courses promoted first with progress indicators
  • Product deals section with relevant opportunities
  • Resources and documentation for Fabric products
  • Related customer accounts and reference sites
  • Commission records and earning opportunities

Interactive Elements

  • Click synonym links to search related terms
  • Filter by product area and resource type
  • Reordered tabs prioritizing courses
  • View course progress on course cards
  • Click results to navigate to details
  • Apply date and product filters

Functionality

  • Search & Synonym Expansion
    • Synonym expansion configured in Salesforce Search Manager groups Fabric with interconnection, Cloud Router, and virtual connection terms
    • Result snippets highlight matched synonym terms using HTML mark elements for visual emphasis
  • Dynamic Result Organization
    • Search results dynamically reorder sections based on search intent: courses for product keywords, deals for account/name searches
    • Product Area filter sidebar replaces Deal Stage filter when product keyword detected in search query
  • Filtering & Real-Time Updates
    • Filters AND-combined together and update result counts in real-time without page reload using client-side logic
    • Apply date and product filters simultaneously to scope search results
  • Data Synchronization
    • Course progress automatically synced from Course_Enrollment__c object and displayed in status badge
