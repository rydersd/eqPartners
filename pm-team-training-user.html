Design Specs

Summary

Individual team member training progress detail view enabling Partner Managers to monitor course completion, certification expiry, and learning path milestones. Provides actions to send reminders, assign courses, and download certificates.

Jobs to Be Done

  • Partner Manager reviews individual team member training progress
  • Send targeted reminders for overdue or expiring courses
  • Assign additional required or elective courses to the team member
  • Download or view completion certificates for compliance tracking
  • Identify training gaps and at-risk certifications before expiry
  • Track learning path milestones toward tier qualification requirements

Design Specification

Primary Content

  • Team member profile header (name, role, email, tier, company, last login)
  • Overall training progress summary with completion percentage and status badge
  • Course-by-course training table (course name, type, status, score, completion date, due date)
  • Per-course progress bars showing module completion percentage
  • Certification status cards with issue date, expiry date, and time-to-expire indicator
  • Learning path progress showing required vs elective courses completed

Interactive Elements

  • Back to Team Training button for navigation
  • Send Reminder button to email team member about overdue courses
  • Assign Course action button to open course assignment dialog
  • Sort and filter controls on training table
  • Download Certificate link for completed courses
  • Expand course rows to view module-by-module details

Functionality

  • Progress Calculation & Tracking
    • Query Contact training assignments from Course_Assignment__c related to User lookup with status
    • Calculate overall progress % as (completed courses / total assigned courses) * 100 and display badge
    • Track per-course completion via CourseProgress__c module records and compute module percentages
  • Certification & Expiry Management
    • Retrieve Certification records linked to completed courses and sort by issue/expiry dates
    • Identify at-risk certifications where Expiry_Date__c < TODAY() + 30 days with warning indicator
    • Display time-to-expire countdown for upcoming certification expirations
  • Course Status & Alerts
    • Auto-flag overdue courses where Due_Date__c < TODAY() and Status__c != 'Completed'
    • Apply visual styling to overdue items to highlight delinquent assignments
    • Filter learning path completion by requirement type (Required vs Elective) for clarity
  • Notifications & Actions
    • Send reminder via email template when Send Reminder button clicked to user email address
    • Generate assignment records when Assign Course action is triggered from dialog
    • Enable certificate download for completed courses via document link generation

Technical Details

Validation & Business Logic

  • Course assignment requires user to be part of account team
  • Certification download only enabled for Completed status with Passed score
  • Reminder email workflow validates email address before send
  • Course expiry calculations use timezone settings of user's account
  • At-risk certifications highlighted in amber when within 30-day window
