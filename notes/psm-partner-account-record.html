Design Specs

Summary

Provides detailed view of a single partner account including tier advancement progress, team training completion status, and recommended actions for the PSM to encourage the partner manager toward next tier achievement.

Jobs to Be Done

  • PSM inspects individual partner account after spotting it on portfolio or dashboard
  • Tier Progress Card shows exactly what's needed for advancement: "Gold requires 8 certs. You have 6. Need: Compliance, Security."
  • Near-Win Alert includes primary CTA: "Encourage Partner Manager" — sends tier data + coaching message
  • At-Risk Alert warns: "This partner may lose Silver status — 3 courses overdue"
  • Team Training shows who's contributing and who's behind — but actions target Partner Manager, not individuals
  • Agentforce NBA recommends: "This partner is 2 courses from Gold — encourage [PM Name]"
  • All CTAs target the Partner Manager — no actions targeting individual contacts
  • Contact drill-down is diagnostic only — "who specifically is blocking progress?"

Design Specification

Primary Content

  • Record header with Account name, Tier badge, Region, Partner Since date, PSM Assigned, Completion %, Team Size
  • Contextual alert banner (Near-Win success or At-Risk warning)
  • Tier Advancement Progress card showing current tier → next tier with progress bar and requirement checklist
  • Team Training tree grid expandable by team member or course with completion status
  • Left sidebar Activity Timeline showing recent engagement and milestone events
  • Right sidebar Training Overview statistics and Agentforce NBA recommendation card
  • Partner Details card with account owner, primary contact, phone, industry, employee count, revenue

Interactive Elements

  • Encourage Partner Manager primary action button with modal workflow
  • Share Tier Summary, Contact Manager, and View Report buttons
  • Tab toggle between "By Team Member" and "By Course" views in tree grid
  • Tree grid expand/collapse controls for parent rows
  • Clickable contact names navigating to Contact Record detail
  • Alert banner contextual action (inherits near-win/at-risk status)

Functionality

  • Record Data Loading
    • Loads account record data via Account object with custom fields: Partner_Tier__c (Gold, Silver, Bronze), Completion_Percentage__c (95%), Team_Size__c (12), Assigned_PSM__c (Sarah Chen)
    • Retrieves related field Partner Since date from Account.CreatedDate and PSM assignment from Account lookup field
  • Tier Status Calculation
    • Evaluates tier advancement logic: if Completion_Percentage__c >= 95% → near-win (green alert), if Completion_Percentage__c <= 50% → at-risk (warning alert)
    • Compares current tier against next tier requirements; displays achievable certifications and gaps needed for advancement
    • Triggers dynamic alert banner rendering based on calculated status with contextual messaging and primary CTA
  • Training Aggregation & Display
    • Aggregates training completion using roll-up summary fields on Account: count of completed courses, in-progress courses, overdue courses
    • Populates tree grid with Contact records linked to Account, joined with SumTotal enrollment data showing course completion status and progress bars per team member
  • Recommendations & Activity Tracking
    • Agentforce NBA integration evaluates Account tier and Completion_Percentage__c to return recommendation text (e.g., "Consider co-marketing engagement")
    • Activity Timeline queries Salesforce Activity (Task, Event) and custom event log records filtering on Account Id, sorted by CreatedDate descending
  • Engagement Action Automation
    • Encourage Partner Manager button triggers workflow that composes email with tier data and sends to Assigned_PSM__c contact email address
    • Email template references Account field values: Partner_Tier__c, Completion_Percentage__c, next tier achievement date estimate
