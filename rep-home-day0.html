Design Specs

About this page

Day 0 state of the rep portal home page — shown to a user on their first login after account activation, or until all 4 Getting Started items are completed. Designed for a user who clicked "Skip" on the first-login orientation wizard (rep-first-login.html). Contrast with rep-home.html which is the Day N returning-user experience.

Day 0 — Experience Cloud implementation notes

Getting Started checklist (persistent)

The checklist is audience-targeted via a custom boolean field Contact.GS_Checklist_Complete__c (false by default). Each of the 4 items maps to a custom boolean on the Contact record (GS_Profile_Done__c, GS_Programs_Viewed__c, GS_First_Deal__c, GS_First_Training__c). The component queries these fields on render and reflects checked/unchecked state. When all 4 are true, GS_Checklist_Complete__c flips to true, and the Audience rule hides the checklist on future logins.

Dismiss behavior: clicking "Dismiss for now" sets a session cookie only — the checklist re-appears on the next login until GS_Checklist_Complete__c = true. This prevents the "skip everything and never see it again" failure mode.

Implementation: Salesforce LWC embedded in an Experience Builder page section, visible only to users where GS_Checklist_Complete__c = false (Audience rule based on Contact field).

Empty state guidance

The Deals and Training modules show contextual empty states when the user has no records. The copy is role-specific (pulled from Contact.Portal_Role__c) and program-specific (linked to the user's Account's active programs via Partner_Program_Member__c). On Day N, these modules show real data and the empty state disappears. The empty state CTA for Training recommends a specific course based on the org's certification gap — the recommended course ID is computed server-side and passed to the component as a prop.

In-App Guidance (IAG) — first-visit prompts

Experience Cloud In-App Guidance (Setup → In-App Guidance) is used to surface contextual tooltips and walkthroughs on first visit. Key prompts for Day 0:

  • Home prompt: Floating prompt on first login — "Getting started? Your checklist is pinned at the top." (Shows once, dismissable)
  • Deals section prompt: Docked tooltip on first visit to the Deals nav item — "Ready to register a deal? Here's what you need: customer name, estimated value, and expected close date. Takes about 2 minutes." (Shows up to 3 times)
  • Training section prompt: On first visit to Training — "Your org needs 6 certifications for Gold tier. Your completions count toward the team total." (Shows once)

IAG prompts are targeted by Profile + Contact.GS_Checklist_Complete__c = false to avoid showing onboarding prompts to experienced users.

Programs section (Day 0 prominence)

The "Your Partner Programs" section is featured prominently on Day 0 because new users need to understand what they're enrolled in and what's expected of them. The data comes from Partner_Program_Member__c junction records linking the Account to program definitions. On Day N, this moves to a sidebar widget or collapsible section — it's reference information, not action-oriented.

Welcome banner (no "back")

The banner copy is controlled by Contact.First_Login__c (date/time, set on first OTP activation). If First_Login__c was within the last 7 days, show "Welcome to Partner Central, [Name]". After 7 days, switch to "Welcome back, [Name]" (the Day N pattern). The orientation link ("Take the orientation →") in the banner links to rep-first-login.html and is hidden on Day N.

Day N — contrast with returning user experience

See rep-home.html for the full Day N wireframe. Key differences on Day N:

  • Banner: "Welcome back, Sarah" — personalized with tier progress badge (4/8 required)
  • Getting Started checklist: hidden (GS_Checklist_Complete__c = true, Audience rule removes component)
  • Deals module: real data — active deals, pipeline value, protection period alerts
  • Training module: real data — in-progress courses, deadline cards (overdue/expiring/upcoming)
  • Programs section: collapsed into a sidebar widget, not full card
  • IAG prompts: different set — "new feature" announcements, deadline nudges, not onboarding basics
  • Activity feed: recent actions log (last 30 days)
  • PSM message: personalized (Marcus has context from prior deals)

Salesforce objects

  • Contact — First name, role, GS checklist booleans, First_Login__c
  • Partner_Program_Member__c — Junction between Account and Program__c, with Status__c
  • Program__c — Program name, tier requirements, certification count
  • Deal_Registration__c — Filtered by Contact.Id; empty check drives empty state
  • Partner_Training__c — Filtered by Contact.Id; recommended course logic runs server-side
