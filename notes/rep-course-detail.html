Design Specs

Summary

Displays detailed course information including learning objectives, prerequisites, module structure with progress tracking, and action buttons to resume or download certificates. Shows recommended related courses.

Jobs to Be Done

  • View detailed course information before enrolling
  • Understand course learning objectives and topics
  • See certification or credit information
  • Launch course from detail page
  • Explore prerequisite and related courses
  • Make informed decision about enrollment

Design Specification

Primary Content

  • Course title, description, track badge (Business/Technical), difficulty level, duration
  • Learning objectives list with checkmark bullets
  • Prerequisites section with completion status and checkmarks
  • Module Progress section with visual stepper bar (42% complete, 3 of 7 modules)
  • Module list with status indicators: completed (checkmark), current (highlighted, numbered), locked (lock icon, numbered)
  • Up Next section with recommended courses (3-card grid)

Interactive Elements

  • Resume Course button (redirects to SumTotal LMS with SSO)
  • Download Certificate button (disabled until completion)
  • View Course links in recommended courses cards

Functionality

  • Content Loading & Display
    • Course detail fetched from Course__c object with metadata: description, duration, level, track, instructor, last_updated
    • Prerequisites section populated from Course__c.Prerequisites__c (comma-separated external IDs); each prerequisite linked to Partner_Training__c records to show completion status
    • Module list fetched from Course__c.Modules__c or LMS directly; includes module names, sequence numbers, estimated times
  • Progress Tracking & Sequencing
    • Module Progress calculated from Partner_LMS_Sync nightly flow: current module index (Partner_Training__c.LMS_Module_Index__c), completion percentage, total module count
    • Visual stepper bar displays completed (gray), current (blue), upcoming (light gray) states based on LMS_Module_Index__c
    • Module list items locked/disabled until all prerequisites complete: IF ANY prerequisite Partner_Training__c.Status__c != 'Completed' THEN show lock icon on current and future modules
    • Module sequencing controlled by Module_Sequence__c field; portal respects order for navigation
  • Actions & Certificate Management
    • Resume Course button visible if Partner_Training__c.Status='In Progress'; generates JWT SSO token and redirects to SumTotal LMS module launch URL with Contact.Email + Course.SumTotal_Course_ID__c + LMS_Module_Index__c
    • Download Certificate button enabled only when Partner_Training__c.Status='Completed' AND Certificate_PDF_URL__c is populated; disabled otherwise with opacity styling
    • Certificate PDF generated asynchronously after completion; link stored in Partner_Training__c.Certificate_PDF_URL__c within 24 hours
  • Related Courses & Recommendations
    • Recommended courses fetched via SOQL query: SELECT Course__c WHERE (Category__c=[current course category] OR Track__c=[current track]) AND Course__c != [current course] ORDER BY Popularity_Score__c LIMIT 3
    • Up Next section displays related courses in 3-card grid with View Course links that navigate to course detail pages

Technical Details

Salesforce & LMS Integration

  • Course__c object with prerequisites linked via Prerequisites__c (formula or comma-separated external IDs)
  • Partner_Training__c record shows Status__c (Not Started|In Progress|Completed), Enrollment_Date__c, Completion_Date__c, Score__c
  • Module progress synced from SumTotal LMS via nightly Partner_LMS_Sync flow; Partner_Training__c.LMS_Module_Index__c tracks current module
  • Prerequisites validation: if any prerequisite Partner_Training__c exists with Status!='Completed', mark modules as locked
  • Certificate PDF generated async after completion; Certificate_PDF_URL__c populated in Partner_Training__c
