Design Specs

Summary

PSM diagnostic view into individual contact training history, certification expiration tracking, and completion patterns. Read-only view enabling PSMs to assess training status during account reviews without direct contact action capability.

Jobs to Be Done

  • PSM drills into a contact from Account Record when something seems stuck
  • Answers the question: Is this one person behind, or a systemic gap?
  • Shows complete training history including elective courses
  • Identifies patterns: started but never completed, no activity in 45+ days
  • Expiration tracking: certs expiring within 30 days highlighted amber
  • SumTotal sync status helps diagnose data freshness issues
  • PSM uses this data for account-level conversations with Partner Manager
  • No action buttons - PSM never contacts individuals directly

Design Specification

Primary Content

  • Diagnostic view banner highlighting read-only PSM access purpose
  • Contact header with name, role, email, and company
  • Training progress widget with overall completion %, status, and last activity date
  • Complete course table with course name, status, completion %, score, due date
  • Certification summary section with issue date, expiry date, and days-to-expire
  • SumTotal sync status indicator (last sync time, next sync scheduled)
  • Breadcrumb navigation back to Account Record

Interactive Elements

  • Sortable columns on course table (course name, status, completion date)
  • Filter controls by Status (Not Started, In Progress, Completed), Track (Business, Technical, Elective)
  • View Full History link to expand all courses including archived/removed courses
  • Export to CSV button for data analysis in accounting/reporting systems
  • Breadcrumb navigation back to parent Account Record
  • NO action buttons (no Send Reminder, Encourage, or direct contact functionality)

Functionality

  • Course Data Retrieval & Syncing
    • Query CourseAssignment__c records for contact and calculate overall completion %
    • Retrieve course history from SumTotal_Sync__c log (read from daily data sync at scheduled time)
    • Display SumTotal_LastSync__c timestamp and scheduled next sync time for transparency
  • Status Flagging & Alerts
    • Flag courses with no activity > 45 days in gray text to indicate stagnation
    • Highlight certifications expiring within 30 days in amber color for visibility
    • Calculate Days_to_Expiration__c = Certification_Expiry__c - TODAY() for countdown display
  • Filtering & Sorting
    • Filter course list by Status and Track based on filter selections and user preferences
    • Sort courses by name, status, or completion date via sortable column headers
    • Maintain filter state during pagination and view transitions
  • Reporting & Export
    • Export to CSV button for data analysis in accounting and reporting systems
    • View Full History link to expand all courses including archived or removed courses
    • Generate compliance audit trail showing all course completions and certification dates

Technical Details

Design Notes

  • Implementation: Custom Lightning Record Page with training LWC components
  • LWC Components: c-partner-training-progress, c-partner-training-detail
  • Diagnostic Banner: Custom component only shows on partner contacts
  • Role: Supporting diagnostic — PSM arrives here FROM Account Record
  • Key Principle: No "Send Reminder", "Encourage" — read-only diagnostic only

Validation & Business Logic

  • PSM access controlled via Contact.Account.Owner and PSM AccountTeamMember
  • SumTotal data refreshed daily at 2 AM UTC via scheduled sync
  • Course history includes archived courses from SumTotal_Archive__c table
  • Expiration highlight only applies if Certification_Expiry__c is populated
