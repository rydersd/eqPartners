Design Notes

Summary

The MDF Request form enables partners to formally request marketing development funds for campaign activities, with budget visibility, compliance checklist, and approval tracking.

Jobs to Be Done

  • Submit formal MDF request for marketing campaign with budget details
  • Provide campaign details and supporting documentation for PSM review
  • Ensure Equinix brand compliance before submission
  • Track request through approval workflow and status changes
  • Access MDF guidelines and eligibility requirements

Design Specification

Primary Content

  • MDF balance display card (available amount, annual total, year-to-date spent)
  • MDF request submission form with multi-section layout
  • Campaign details: name, category, activity type, description
  • Budget request: requested amount, cost breakdown, Equinix contribution calculation
  • Equinix brand guidelines compliance checklist with links
  • File upload area for supporting materials and campaign plan documents
  • Previous campaign references and approval history
  • Approval workflow status tracker with timeline

Interactive Elements

  • Fill in campaign detail fields with inline help text
  • Upload campaign plan documents with drag-and-drop support
  • Select campaign type from dropdown with category descriptions
  • Set budget amount with real-time Equinix contribution calculation
  • Toggle brand compliance checklist items with visual confirmation
  • Submit request or Save as draft for later completion

Functionality

  • Budget Calculation & Validation
    • Real-time available budget calculation: MDF_Fund__c.Allocated - sum(approved_campaigns_ytd) with remaining balance display
    • Form validation: All required fields, budget ≤ available balance, compliance checklist completed before submission
  • Cost Management & Automation
    • Cost-share calculation: Partner_Amount + Equinix_Amount = Total_Budget per Partner_Agreement__c terms for accurate allocation
    • Draft auto-save every 30 seconds with local storage fallback to prevent data loss
  • Workflow & Notification
    • Auto-route to assigned PSM upon submission with status notification and audit trail creation
    • Approval workflow status updates pushed to partner dashboard in real time for immediate visibility
