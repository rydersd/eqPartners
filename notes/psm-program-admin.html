Design Specs

Summary

Centralized admin console for configuring partner program parameters including tier definitions, scoring weights, course requirements, commission rates, and system integrations. System admins use this interface to manage program-wide settings without code changes.

Jobs to Be Done

  • Admin configures tier thresholds and scoring model without developer help
  • Changes recalculate all partner scores immediately (batch job)
  • Course requirement changes reflected in all training widgets
  • SumTotal sync monitoring with alerting when sync fails or stale (>24 hours)
  • Manual re-sync for specific accounts or full batch
  • Error log shows field-level validation failures with API responses
  • Commission rates configurable per tier with accelerator bonuses
  • Notification templates editable with merge fields
  • All config changes logged with admin identity and timestamp

Design Specification

Primary Content

  • Tabbed interface with six configuration sections (Tier Configuration, Scoring Weights, Course Requirements, Sync Monitor, Commission Settings, Notifications)
  • Tier Configuration: Bronze/Silver/Gold threshold scores, names, benefits descriptions
  • Scoring Weights sliders: Training Completion %, Revenue Target %, Customer Engagement %, Certification Retention % (must total 100%)
  • Course Requirements table: Course Name, ID, Track, tier requirements (checkboxes), display order, active status
  • SumTotal Sync Monitor: Health indicator, last sync timestamp, records synced count, sync frequency display
  • Commission Configuration: Gold/Silver/Bronze base rates, revenue accelerator thresholds, certification bonus thresholds
  • Notification Templates: Checkboxes for enabled notifications with next scheduled count, edit/test buttons
  • Configuration Audit Log: Last 10 changes with timestamps, admin names, descriptions of changes

Interactive Elements

  • Inline edit inputs for tier thresholds and rates
  • Scoring weight sliders with % display and auto-normalization to 100%
  • Add Course Requirement button and course table Edit buttons
  • Import from CSV button for bulk course requirements
  • Manual Re-Sync Now, View Error Log, and Sync Detailed Report buttons
  • Edit Email Templates, Test Notifications, and View Notification History buttons
  • Save Configuration and Revert Changes buttons on each tab
  • Checkbox toggles for notification template activation

Functionality

  • Configuration Loading & Storage
    • Loads all program configuration from Custom Metadata Types: Tier_Configuration__mdt (Bronze/Silver/Gold thresholds), Scoring_Model__mdt (weight percentages), Course_Requirements__mdt (course roster with tier mapping)
    • Displays current values in tabbed interface: Tier Configuration (threshold scores, benefits), Scoring Weights (sliders totaling 100%), Course Requirements (table with active/inactive status)
  • Tier & Scoring Recalculation
    • Tier threshold changes trigger batch job: recalculates all Partner_Scorecard__c records using updated thresholds within 5 minutes via Salesforce Batch Apex
    • Scoring weight changes auto-normalize: if total > 100%, redistributes proportionally; blocks save if < 100% with validation error
    • Course requirement updates immediately invalidate Partner_Training_Cache__c records; partners see recalculated requirements on next dashboard refresh
  • System Integration Monitoring
    • SumTotal sync health pulled from Integration_Health__c.Status__c and last Platform Event CreatedDate timestamp; displays red indicator if sync stale > 24 hours
    • Manual Re-Sync Now button invokes SumTotal_Integration_Service.startFullSync() apex class which queues a scheduled action batch job for enrollment data sync
  • Commission & Payment Configuration
    • Commission configuration stores to Commission_Model__c custom metadata with base rates per tier (Gold 15%, Silver 10%, Bronze 5%), revenue accelerator thresholds ($100K+), certification bonus multipliers
    • Changes take effect for next deal calculation and payment processing; historical commission records unaffected
  • Notification & Audit Management
    • Notification template changes saved to Email_Template__c records with sample merge field preview (e.g., {!Partner.Name}, {!Tier__c}, {!Completion_Percentage__c})
    • All configuration changes logged to Program_Config_Audit__c child record: admin user ID (UserId), timestamp (CreatedDate), change_description__c with before/after values
    • Revert Changes button reverts current form to last saved configuration state; no undo capability for previous saves
