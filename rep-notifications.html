Design Notes

Summary

Centralized notification hub showing recent alerts with unread indicators, category filtering, and quick actions. Sarah Connor (CloudBridge Solutions) notifications: expired cert alert (Security Fundamentals), Marcus Chen support message, deal registered confirmation (Global Finance Corp), upcoming QBR Feb 28. Partners can view notification details, filter by category, and navigate to related records directly from the notification interface.

Jobs to Be Done

  • View unread notifications at a glance with badge indicator on bell icon
  • Access recent notifications via dropdown menu without full page load
  • Expand a notification to see full context and related record details
  • Filter notifications by category to focus on relevant updates
  • Mark notifications as read individually or mark all at once
  • Navigate to related records (deals, commissions, training) from notifications
  • Access full notification history and customize preferences

Design Specification

Primary Content

  • Bell icon header with unread badge count
  • Dropdown overlay showing recent notifications with category tabs (All, Deals, Training, System)
  • Notification items with: unread dot indicator, category icon, title, category label, timestamp
  • Expanded notification detail card with icon, title, full description, quick summary metadata, and action buttons
  • Grouped notification list organized by time periods (Today, Yesterday, This Week)
  • Category filter chips showing counts for each notification type

Interactive Elements

  • Bell icon click opens dropdown overlay anchored to header
  • Dropdown tabs filter visible notifications by category without page reload
  • Mark All Read button in dropdown header clears unread indicators and updates badge
  • Notification item click expands detail view with contextual metadata
  • Category filter chips toggle notification visibility in grouped list
  • Action buttons: View Deal Detail, Request Extension, Contact PSM, Dismiss
  • Links to Notification Preferences (settings icon) and full History page

Functionality

  • Real-Time Updates & Badge Management
    • Unread count badge updates in real-time via Salesforce push notifications using CometD streaming
    • Custom Notifications API triggers in-app alerts via Flow or Apex for deal changes, expirations, commissions, training, and PSM messages
  • Notification Filtering & Display
    • Category tabs filter notifications without page reload by toggling visibility of items based on category
    • Timestamp bucketing groups notifications by relative time periods (Today, Yesterday, This Week) using server-side date calculations
    • Dropdown and expanded list views display different formatting of same notification data
  • Dynamic Context Loading
    • Notification detail dynamically loads record context (customer name, deal value, stage, PSM, products) from related Salesforce objects
    • Deep links from notification actions navigate to relevant record pages while preserving back-navigation context
  • Read State & Archive Management
    • Mark Read actions update read status via async API calls, triggering immediate UI updates
    • Dismiss button removes notification from view and archives it in notification audit table
    • Auto-dismiss rules: system announcements expire after event date; read notifications archive after 30 days via scheduled job

Technical Details

Validation & Business Logic

  • Notifications persisted in Custom Object with link to User and source record
  • Real-time updates via Salesforce streaming API (CometD)
  • Deep link construction validates record access before navigating
  • Archive retention policy enforces 30-day read notification removal
