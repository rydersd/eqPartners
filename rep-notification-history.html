Design Notes

Summary

Displays a searchable, filterable history of all partner notifications with read/unread status, delivery channel indicators, and quick actions. Partners can track important alerts, regulatory updates, and business communications across 90 days of history with export capability.

Jobs to Be Done

  • Review all past notifications and alerts across time periods
  • Distinguish between read and unread messages at a glance
  • Filter by category: deals, commissions, training, partner updates
  • Search for specific notifications by keyword
  • Understand which delivery channels carried each notification
  • Mark notifications as read and manage notification volume
  • Export notification history for record-keeping or compliance

Design Specification

Primary Content

  • Summary statistics: total notifications (90 days), unread count, and breakdowns by category (Deal, Commission, Training, PSM)
  • Full notification history table with columns: Notification text, Category badge, Delivery channels, Date/time, Actions
  • Visual indicators for unread status: left accent bar, bold text styling
  • Delivery channel icons showing which channels (in-app, email) delivered each notification
  • Breadcrumb navigation and link to Preferences page
  • Paginated results with page count and navigation controls

Interactive Elements

  • Status filter chips: All, Unread, Read — toggle to filter notifications
  • Category dropdown: All Categories, Deal Registration, Commissions, Training, Partner Success, System
  • Time period selector: Last 7 days, Last 30 days, Last 90 days, All Time
  • Search input for free-text filtering across notification text
  • Mark as Read button for unread notification rows
  • Export CSV button to download full notification history
  • Pagination controls with page numbers and previous/next navigation

Functionality

  • Filtering & Query Operations
    • Server-side filtering executes via indexed queries on category, read status, and created date fields
    • Status chip filtering applies across current time period without page reload using SOQL
    • Search operates across notification text and metadata fields using full-text search indexes
  • Status & Read State Management
    • Unread badge counter auto-updates when notifications marked as read via API call
    • Delivery channel icons reflect user preferences stored at time of notification creation
    • Row styling toggles between bold (unread) and normal weight when status changes
  • Data Export & Retention
    • CSV export includes all visible columns plus full notification body text from Salesforce records
    • 90-day default retention with archive capability for older notifications in separate table
  • Navigation & Link Management
    • Row clicking or deep links navigate to source record pages while preserving back-navigation history
    • Pagination controls manage result set across filtered data using limit/offset

Technical Details

Validation & Business Logic

  • Notification records stored as Custom Object linked to User record
  • Category and read status fields indexed for fast query performance
  • Delivery preferences checked at notification creation time, not retrieval
  • Archive records preserved with separate audit trail for compliance
