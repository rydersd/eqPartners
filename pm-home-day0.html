Admin Home — Day 0 · Design Notes

When this page shows

Audience rule: Contact.Admin_First_Login__c = true AND Admin_GS_Complete__c = false. Day 0 and Day N are two Audience-targeted variants of the same EC Page — same URL, different component visibility. When all 4 admin setup steps complete, Admin_GS_Complete__c flips to true and the Day N variant becomes visible on next navigation.

Day 0 vs. Day N differences

  • Welcome copy: "Welcome to" vs. "Welcome back"
  • Setup CTA: Banner visible on Day 0; hidden when Admin_GS_Complete__c = true
  • Left top: Cloudbridge Setup card (Day 0) vs. Tier Progress (Day N)
  • Left middle: Your Portal wayfinding (Day 0 only) → replaces with Team Activity on Day N
  • Left bottom: Programs & Marketing (both, refreshed on Day N)
  • Right top: Contacts empty state (Day 0) vs. full Key Contacts (Day N)
  • Right bottom: LinkedIn feed (both)
  • IAG sets: Admin Day 0 set (first-login prompts) vs. Day N set (data-gap prompts)

Cloudbridge Setup card

Branded as "Cloudbridge Setup" (not "Admin Setup") — the company's name is more motivating than a generic role label. This card is informational: it shows step status so the admin knows where they are. There is only one active CTA for setup — in the welcome banner. The footer "Next step →" is a lightweight secondary link, not a primary button, to avoid redundant CTAs. The full guided wizard lives at pm-admin-setup.html.

SF Contact booleans: Admin_GS_Profile__c, Admin_GS_Requests__c, Admin_GS_Training__c, Admin_GS_Backup__c → all true = Admin_GS_Complete__c = true.

Programs module — Snowflake pattern

Snowflake's Partner Marketing Center surfaces co-brandable assets, 50/50 MDF, competitive spiffs, joint demand-gen, and field marketing tools proactively. This module applies the same principle: Day 0 is the highest-intent moment for program adoption. Partners see what's available without hunting through resource libraries. Each card shows the incentive value and a direct CTA.

SF objects: Partner_Program__c, Partner_Program_Member__c, MDF_Request__c.

Accessibility

  • Setup steps: role="list" / role="listitem"; current step uses aria-current="step"
  • Welcome setup block uses role="status" for live region announcing progress
  • Contact links open mailto: or Salesforce Scheduler — keyboard navigable
  • LinkedIn post images carry descriptive role="img" + aria-label
  • Color is never the sole indicator of step state — icon + text label both present
