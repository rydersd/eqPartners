Figma Spec Block

Page Name
pm-team-management
Portal
Partner Manager Portal
Primary Content
  • Page header with organization info and action buttons
  • Invite new user form with role selection and access permissions
  • Active users table with status, login history, and course completion
  • Pending invitations list with resend/revoke actions
  • License usage sidebar with seat allocation and breakdown
Interactive Elements
  • Invite user form submission
  • User deactivation (preserves history)
  • Role editing and permissions management
  • Bulk actions: assign training, deactivate, change role
  • Resend and revoke invitation actions
  • MFA reset capability
Functionality
  • SF Object: Partner_Contact__c → User (Experience Cloud) via PermissionSetAssignment
  • Invite flow creates Contact + triggers Experience Cloud User provisioning
  • Email invitation via Marketing Cloud with MFA enrollment trigger
  • Deactivate = IsActive=false on User record (preserves history)
  • License count from UserLicense query (Experience Cloud login-based)
Design Brief
  • Accessibility: table has proper th scope, status badges use both color + text
  • Focus management for invite form validation
  • Form labels use uppercase with letter-spacing
  • Status badges: Active (green var(--wf-ink, #1e2a3a)), Invited (amber var(--wf-amber, #8b7745)), Deactivated (red var(--wf-red, #8b4553))
  • Responsive layout: main column + sidebar, collapses on tablet/mobile
  • Consistent typography and spacing throughout
