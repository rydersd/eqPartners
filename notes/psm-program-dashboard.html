Design Specs

Summary

Provides PSM leadership with high-level partner program health overview including portfolio tier distribution, training completion trends, and spotlight on near-win partners ready for advancement. Dashboard enables filtering by tier/region and data export for reporting.

Jobs to Be Done

  • Review overall program health and near-win partners at a glance
  • Identify partners within 15% of tier advancement for targeted encouragement
  • Track training completion trends and spot at-risk accounts
  • Filter portfolio by tier and region to focus on specific segments
  • Export filtered data to CSV and schedule recurring reports

Design Specification

Primary Content

  • KPI metric cards: Total Partners, Avg Completion %, Near-Win Count, At-Risk Count, Gold Tier Count with trend indicators
  • Near-Win Spotlight section with 6 partner cards showing name, tier, completion %, courses needed, assigned PM, and last contact date
  • Program Analytics section with Tier Distribution horizontal stacked bar (Gold/Silver/Bronze/Registered counts)
  • Completion Trend 6-month line graph showing month-over-month progression
  • Top 5 Partners and Bottom 5 Partners comparison charts with completion percentages
  • Partner Portfolio Snapshot data table with 12-row pagination showing Account, Tier, Team Size, Completion %, Courses to Next, Status, Region, Last Activity, Actions

Interactive Elements

  • Tier filter dropdown (All, Bronze, Silver, Gold, Registered)
  • Region filter dropdown (All, US West, US East, EMEA, APAC)
  • Period selector dropdown (Last 6 Months, Last 12 Months, Last 90 Days, YTD)
  • Encourage action button on each Near-Win Spotlight card
  • Encourage and View action links in Partner Portfolio table
  • Clickable account names navigating to Partner Account Record page
  • Refresh button to manually reload dashboard data
  • Export CSV button to download filtered table data
  • Schedule Report button to set up recurring dashboard emails

Functionality

  • KPI Aggregation & Calculation
    • Queries Partner_Scorecard__c aggregates grouped by Account: calculates Total Partners (count), Avg Completion % (AVERAGE(Completion_Percentage__c)), Near-Win Count (count where Near_Win__c = true), At-Risk Count (count where At_Risk__c = true), Gold Tier Count (count where Partner_Tier__c = 'Gold')
    • Loads KPI metric cards with trend indicators showing period-over-period change
  • Dynamic Filtering & Data Queries
    • Tier filter applies SOQL WHERE condition: Partner_Tier__c IN (selected values from dropdown); Region filter applies: Account.BillingCountry IN (selected regions)
    • Period selector filters by date range: Last_Activity__c >= TODAY() - N days (Last 6 Months = 180 days, YTD, etc.)
  • Near-Win Spotlight Identification
    • Queries Partner_Scorecard__c with formula: (Completion_Percentage__c >= 85% AND Partner_Tier__c != 'Gold') OR (Completion_Percentage__c >= 90% AND Partner_Tier__c = 'Silver'); sorts by Courses_To_Next_Tier__c ascending to surface closest candidates
    • Displays top 6 prospects with Account Name, Tier badge, Completion %, Courses Needed, Assigned PSM, Last Contact date
  • Analytics Visualization & Trending
    • Tier Distribution chart pulls roll-up counts from Account grouped by Partner_Tier__c field (Gold/Silver/Bronze/Registered); displays as horizontal stacked bar
    • Completion Trend 6-month line graph queries Partner_Monthly_Snapshot__c records for monthly completion percentage progression
    • Top 5/Bottom 5 Partners charts sort table by Completion_Percentage__c DESC/ASC and display first 5 accounts with completion bars
  • Portfolio Management & Export
    • Partner Portfolio table displays filtered Partner_Scorecard__c records with pagination (12 rows per page); columns include Account, Tier, Team Size, Completion %, Courses to Next, Status, Region, Last Activity, Action buttons
    • Encourage action button opens modal to compose and send predefined encouragement message to Assigned_PSM__c contact with tier advancement data
    • Export CSV button generates downloadable file with filtered Account Name, Partner_Tier__c, Completion_Percentage__c, Status columns
    • Schedule Report button saves Report_Schedule__c record and triggers Flow to send recurring dashboard email on selected frequency

Technical Details

Key Objects

  • Account — Partner account record
  • Partner_Scorecard__c — rollup of training metrics per account
  • Partner_Training__c — individual contact training record
  • Partner_Tier_History__c — audit trail of tier changes

Validation & Business Logic

  • Near-Win threshold: Configurable via custom metadata (default 15% gap to next tier)
  • Dashboard auto-refreshes when batch sync Platform Event fires (hourly)
  • Tier demotion: Auto-triggered if completion drops below minimum (e.g., Silver requires 75%+)
  • At-Risk flag: Set when completion 2 courses overdue
  • Cannot approve deal if partner tier = "Registered" (bronze minimum)
