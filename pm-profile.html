Page purpose

Full user profile settings page, reached via the avatar popover in the app header. Covers personal info, security, notifications, and privacy & data. Language and timezone live here — not in the onboarding wizard.

Tab structure

  • Profile — name, title, phone, LinkedIn, language, timezone, date/number format, read-only account fields
  • Security — MFA methods, password, active sessions
  • Notifications — per-category email/in-app toggles; security alerts cannot be disabled
  • Privacy & Data — consent log, analytics opt-out, data export, account deletion, connected apps

Informed by HubSpot (language in Profile, timezone in Preferences), Salesforce EC (Personal Info | Login tabs), and Okta (session management pattern).

Key design decisions

  • Language + timezone in Profile tab per explicit product direction — closes Jira gap
  • Email and portal role are read-only; edits require PSM or primary admin
  • MFA callout on Security tab reads from localStorage; hides when MFA done
  • Security alert email toggle is forced-on and disabled
  • Destructive actions (delete account) use a separate red button style, not ghost
  • Deep-linking via hash: #security, #notifications, #privacy

Accessibility

  • role="tablist" / role="tab" / role="tabpanel" per ARIA APG tab pattern
  • Arrow key navigation cycles tabs; Enter/Space activates
  • Each toggle has its own aria-label (not relying on proximity)
  • Save confirmations use aria-live="polite"
  • Disabled inputs communicate constraints via field-hint text

Salesforce / CRM mapping

  • Language → User.LanguageLocaleKey
  • Timezone → User.TimeZoneSidKey
  • MFA status → User.MFA_Verified__c
  • Notification prefs → Notification_Preferences__c
  • Connected apps → ConnectedApplication via OAuth token records
