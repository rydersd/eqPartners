Design Notes

Summary

Manages MDF reimbursement requests from partners including budget allocation tracking, approval workflows, and payment processing. Finance and PSM teams use this interface to validate reimbursement eligibility and reconcile expenses against approved PoPs.

Jobs to Be Done

  • Process partner reimbursement requests for program investments
  • Validate reimbursement eligibility and required documentation
  • Track budget usage and reimbursement spend-down
  • Manage reimbursement approval workflows
  • Reconcile partner expenses against approved budgets
  • Generate reimbursement reports for finance reconciliation

Design Specification

Primary Content

  • KPI header cards: Pending Reimbursement count, Total Pending Amount, Processed This Month
  • Reimbursement Request Queue table showing Partner, Campaign/Activity, Amount, Approval Status, Payment Status, Payment Date
  • Budget Impact Analysis cards by tier (Gold/Silver/Bronze) showing remaining budget, allocation percentage, and budget burn-down bar
  • Recent Reimbursements timeline showing paid reimbursements with dates and amounts
  • Right rail Activity/Agentforce tabs with submission timeline and AI processing recommendation
  • Right rail Actions panel with Approve Claim, Request Docs, and Escalate buttons

Interactive Elements

  • Click request row to expand and view full details and attachments
  • Approve Claim button in right rail to approve selected reimbursement
  • Request Docs button to send documentation requirement message to partner
  • Escalate button to flag request for higher-level review
  • Status badge updates on approval/payment status
  • Filter by tier, status (Pending, Approved, Processing, Paid) and date range
  • Activity/Agentforce tab toggle

Functionality

  • Reimbursement Request Loading & Eligibility
    • Queries all Reimbursement_Request__c records linked to approved MDF_PoP_Submission__c records (filtered where Status__c = 'Approved'); loads Partner Account, Category, Request_Amount__c, Submitted_Date__c
    • Request_Amount__c auto-populated from linked PoP submission; verified against MDF_Budget_Allocation__c remaining budget to validate eligibility
  • Approval & Payment Status Tracking
    • Approval Status tracks workflow state machine: Pending → Approved → Processing → Paid with timestamp on each transition; displays badge with color coding
    • Payment Status reflects finance integration via API: Pending → Processing → Paid with Payment_Date__c stamp on completion; syncs with backend payment system
  • Budget Impact Analysis
    • Budget Impact cards calculate per tier (Gold/Silver/Bronze): Remaining_Budget__c = Total_Tier_Budget__c - Sum of Paid Reimbursements (SOQL sum)
    • Budget bar fills proportionally: (Total_Budget - Remaining) / Total_Budget * 100; displays burn-down visualization and allocation percentage
  • AI-Powered Recommendations
    • Agentforce NBA analyzes Reimbursement_Request__c to recommend approval/escalation based on: budget availability, Reimbursement_Line_Item__c documentation completeness, PoP validation status, historical approval patterns
  • Approval & Escalation Actions
    • Approve Claim button updates Reimbursement_Request__c.Status__c to 'Approved', creates Finance_Payment_Request__c record, and triggers payment workflow email to finance team
    • Request Docs action sends template email to Partner contact with missing Reimbursement_Line_Item__c documentation requirements list and 5-day deadline
    • Escalate action creates Task for finance manager, flags Request__c.Escalation_Required__c = true, and sends notification email; captures escalation reason
    • Recent Reimbursements timeline queries Reimbursement_Request__c where Status__c = 'Paid', sorted by Payment_Date__c DESC, displays last 4 paid claims with date and amount

Technical Details

Key Objects

  • Reimbursement_Request__c: Partner_Account__c, Request_Amount__c, Category__c, Status__c, Submitted_Date__c
  • Reimbursement_Line_Item__c: Request__c, Description__c, Amount__c, Category__c, Supporting_Doc_URL__c
  • Reimbursement_Approval__c: Request__c, Approver__c, Status__c, Approval_Date__c, Comments__c

Validation & Business Logic

  • Request amount cannot exceed available budget allocation
  • Supporting documentation required for all line items
  • Multi-level approval based on request amount threshold
  • Reimbursement rate limited per category per fiscal year
  • Duplicate request prevention within 24-hour window
