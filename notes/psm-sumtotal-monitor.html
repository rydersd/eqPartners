Design Specs

Summary

Monitors the SumTotal LMS to Salesforce integration health, displaying real-time sync status, error logs, and historical performance metrics. Allows PSMs to diagnose sync failures and manually trigger synchronization operations.

Jobs to Be Done

  • Monitor SumTotal LMS integration health with real-time status indicators
  • Track sync completion, record counts, success rates, and failure patterns
  • Identify and diagnose sync failures with error details and classification
  • Manually trigger syncs and retry failed records without developer assistance
  • Configure alerts for stale syncs, high failure rates, and integration issues
  • Maintain audit trail of all sync operations with timestamp and result logging

Design Specification

Primary Content

  • Five KPI cards: Last Sync, Records Synced, Failed Records, Success Rate, Next Scheduled
  • Integration Status indicator showing "Healthy" connection state
  • Error Log table with Record ID, Contact Name, Error Type, Error Message, Timestamp
  • Sync History table with 7-day records showing Sync Date & Time, Records Processed, Failed, Success Rate, Duration, Status
  • Apex Jobs & Scheduled Flows section tracking automated sync processes
  • Manual Sync Trigger card with warning alert for impact
  • Alert Settings & Configuration section for notification thresholds (stale sync, failed records, alert recipients)
  • System Health Summary card with 7-Day Uptime, Avg Sync Time, Avg Success Rate

Interactive Elements

  • Manual Sync Trigger button to execute on-demand synchronization
  • Configuration inputs for stale sync threshold (hours), failed record threshold, alert recipients (email)
  • Save Configuration and Reset to Defaults buttons
  • Open Apex Jobs Monitor link to Salesforce Setup

Functionality

  • Scheduled Sync Job Execution
    • SumTotal_CourseCompletion_Sync batch job (Scheduled Apex class) runs daily at 6:00 AM EST and 6:00 PM EST on schedule via Salesforce Apex Scheduler
    • KPI cards display Last Sync timestamp, Records_Synced__c count, Failed_Records__c count, Success_Rate__c %, and Next_Scheduled_Sync__c datetime
  • Contact & Course Data Synchronization
    • Batch job processes Partner_Training__c and Contact records querying SumTotal LMS API endpoints for enrollment and completion data; maps to custom fields: Course_Completion_Date__c, Certification_Status__c, Training_Score__c, Completion_Percentage__c
    • Integration Status indicator displays "Healthy" if last sync succeeded within 24 hours; shows "Warning" if 24-48 hours stale, "Error" if > 48 hours stale
  • Error Detection & Classification
    • Validation errors logged on missing courses (Course not found in Salesforce), inactive contacts (Contact.Status__c = 'Inactive'), or field mapping failures; triggers Integration_Error_Log__c creation with Error_Type__c and Error_Message__c
    • Error Log table displays Record ID, Contact Name, Error Type classification, Error Message detail, CreatedDate timestamp with search/filter capability
  • Manual Sync & Alert Configuration
    • Manual Sync Trigger button executes SumTotal_Integration_Service.startSync() apex method on-demand with warning alert "This will process all pending enrollments"; blocks execution if sync already running (Scheduled_Actions with Status = 'Running')
    • Alert Settings form captures configurable thresholds: Stale_Sync_Hours__c (alert if LastSyncDate > 48 hours), Failed_Records_Threshold__c (alert if count > 100), Alert_Recipients__c (email comma list)
    • Sync History table queries Integration_Sync_Log__c records for 7 days, displays Sync_Date_Time__c, Records_Processed__c, Failed_Count__c, Success_Rate__c %, Duration_Minutes__c, Status__c badge
  • System Health Monitoring
    • System Health Summary card calculates 7-Day Uptime (sync_success_count / total_sync_count * 100), Avg Sync Time (AVERAGE Duration_Minutes__c), Avg Success Rate (AVERAGE Success_Rate__c) from Integration_Sync_Log__c
    • Open Apex Jobs Monitor link navigates to Salesforce Setup → Monitoring → Apex Jobs page for real-time batch job status

Technical Details

System Integration

  • Real-time SumTotal LMS API integration syncing twice daily (6:00 AM and 6:00 PM EST)
  • Salesforce batch job monitoring for SumTotal_CourseCompletion_Sync
  • Debug log access for troubleshooting failed batch jobs
  • Configurable alert thresholds for stale syncs and high failure rates
