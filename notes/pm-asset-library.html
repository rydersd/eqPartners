Design Notes

Summary

Co-branded marketing asset library enabling partner managers to browse, search, preview, and download Equinix-approved materials while maintaining brand compliance and providing custom asset request options.

Jobs to Be Done

  • Access Equinix-approved co-branded marketing materials
  • Download assets for partner marketing activities
  • Ensure brand compliance with guidelines reference
  • Request custom branded materials when needed
  • Track which assets are most used by team

Design Specification

Primary Content

  • Co-branded asset library with 9+ marketing materials organized by category
  • Asset cards with preview thumbnails, type badges, file format/size, and last updated date
  • Category sections: Logos, Email Templates, Social Media Templates, Presentation Decks, Case Studies, One-Pagers
  • Brand guidelines reference panel with usage rules and compliance standards
  • Search and filter toolbar for quick discovery by type and keyword
  • Custom co-branded asset request form link for additional materials not in library

Interactive Elements

  • Browse assets by category with visual cards and metadata
  • Search by keyword or asset type for quick discovery
  • Preview asset thumbnail before committing to download
  • Download button offering multiple export formats when applicable
  • Request custom co-branded asset form triggering partner request workflow
  • View brand guidelines overlay with usage rules and compliance standards

Functionality

  • Search & Discovery
    • Full-text search across asset metadata via SOQL full-text search (FTS) query executing FIND '{!searchKeyword}' IN ALL FIELDS against Content_Asset__c records with keyword, title, and description fields indexed
    • Search result ranking by relevance score from SOQL FIND response sorted by match quality and last-modified date using ORDER BY LastModifiedDate DESC
    • Real-time search suggestion via SOQL queries returning top 10 asset names matching input prefix for autocomplete UX improvement
  • Filtering & Navigation
    • Faceted filtering by asset type and category using dynamic picklist queries from Content_Asset__c.Asset_Category__c and Asset_Type__c fields with result count aggregation via GROUP BY SOQL
    • Multi-select filter application combining keyword search with picklist filters using WHERE clause conditions like "WHERE Asset_Category__c IN ('Logo', 'Template') AND Title LIKE '%{keyword}%'"
    • Filter count display showing matching result totals per category updated dynamically via JavaScript event listeners on checkbox changes triggering AJAX calls to /api/asset-filter-count
  • Download Management & Analytics
    • Download tracking logging which partner downloads which assets via after-insert Apex trigger on Asset_Download__c junction record capturing Partner__c, Content_Asset__c, and CreatedDate timestamp
    • Download counter incrementing Content_Asset__c.Download_Count__c field via roll-up summary field counting related Asset_Download__c records
    • Download analytics feeding dashboard with metrics including Total Downloads, Trending Assets (downloaded in last 30 days), and Partner Engagement Score calculated as SUM(download_count) per Partner
  • Popular Assets & Recommendations
    • Popular assets ranking calculated via formula field Content_Asset__c.Popularity_Score__c = Download_Count__c + (DAYS_BETWEEN(TODAY(), CreatedDate__c) / 100) weighting recent downloads higher than older ones
    • Hero section featured assets curated from top 5 assets by popularity score via SOQL ORDER BY Popularity_Score__c DESC LIMIT 5
    • Recommendations component showing partner-specific suggested assets based on Asset_Category__c relevance to partner Tier__c and Territory__c matching
  • Asset Requests & Custom Orders
    • Asset request form integration allowing partners to submit custom co-branded asset requirements creating Asset_Request__c record with requested specifications (Logo_Variant__c, Sizing__c, Text_Customization__c)
    • Custom asset approval workflow via Process Builder routing Asset_Request__c to Marketing_Team_Queue__c with approval chain requiring Manager and Brand Manager sign-off
    • Request status tracking updating Asset_Request__c.Status__c through workflow states ('Submitted', 'In Review', 'Approved', 'In Production', 'Ready for Download')
  • Brand Compliance & Governance
    • Brand guidelines display rendering Brand_Guidelines__c record content including usage rules, color codes, typography standards, and prohibited applications
    • Brand book PDF link generating direct download URL from Brand_Guidelines__c.PDF_Attachment__c stored as ContentDocument with version tracking
    • Compliance warning overlay appearing before download for assets with usage restrictions showing required acknowledgment checkbox that must be checked before download allowed

Technical Details

Key Objects & Data

  • Content_Asset__c — Represents each downloadable file (Logo, Template, Presentation, etc.)
  • Asset_Category__c — Picklist categorizing assets by type
  • Asset_Download__c — Junction table tracking downloads per Partner with timestamp
  • Asset_Request__c — Custom asset request records routing to Marketing team for fulfillment
  • Brand_Guidelines__c — Single record containing policy document and usage rules
