Design Note — Agreement Generation via Salesforce Document Builder

Agreements are generated using Salesforce Document Builder (Lightning Document Builder, generally available as of Spring '24). PAM selects agreement type (Bronze/Silver/Gold PPA, JBP, Amendment), the system pulls: legal entity name, D&B verified address, tier, product authorizations, and commission rate table from the partner account record. DocBuilder merges into a branded PDF template. E-signature is handled via Salesforce eSignature (DocuSign integration via Salesforce Agreements/CLM), with envelope status synced back to the agreement record in real time. For escalation briefs specifically, see psm-escalation-brief.html — those use Agentforce Document Generation.
