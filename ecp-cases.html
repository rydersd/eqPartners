Design Specs

Summary

Centralized support case management enabling customers to submit, track, and escalate infrastructure issues while monitoring SLA compliance and accessing self-service resources. S.H.I.E.L.D. (customer contact Maria Hill) support cases related to Equinix infrastructure interconnection services via Stark Industries reseller, including connectivity questions about pending Fabric virtual connections.

Jobs to Be Done

  • Submit new support tickets with category and priority selection
  • View case status and track resolution progress
  • Review escalation paths and SLA response times
  • Access self-service knowledge base to resolve issues
  • Monitor account health through case metrics and trends

Design Specification

Primary Content

  • KPI summary: Open Cases, Avg Resolution Time
  • Create New Support Case expandable form section
  • Open Cases table
  • Recently Closed Cases table with resolution time and CSAT ratings
  • Case Activity Timeline for selected case with status updates
  • Knowledge Base Quick Links for common topics
  • Support Escalation Path showing response times by level

Interactive Elements

  • Expandable form for creating new support cases with category, priority
  • Click case ID to view full details and communication thread
  • File attachment upload for cases
  • Knowledge base article cards linking to troubleshooting guides
  • Filter and sort case tables by status, priority

Functionality

  • Case Management & Routing
    • Salesforce Case object creation with auto-assignment based on category and priority triggering Routing Assignment rules
    • Real-time escalation path determination calling custom escalation apex class to evaluate priority, case age, and SLA breach risk
    • Case ownership transfer to secondary queue when assignment rule queue is unavailable
  • Automation & SLA Tracking
    • SLA clock start/stop automation tied to case status changes (Open→In Progress→Closed) via EntitlementProcess workflow
    • Automated milestone tracking generating breach warnings 24 hours before target resolution time
    • Email notification to support manager on SLA breach condition via Case trigger with Messaging.sendEmail() call
  • Knowledge Integration & Self-Service
    • Auto-suggested KB articles matched to case category and keywords using full-text search API returning related articles sorted by view count
    • KB article click tracking stored in ArticleViewTracker__c junction object for search result ranking improvement
    • Quick-link component rendering most viewed articles by metro location using SoQL aggregation query
  • Reporting & Quality Assurance
    • CSAT rating capture on case closure with rating stored in Case.CSAT_Score__c custom field and aggregated to Account.Avg_CSAT__c rollup summary
    • Closed case metrics aggregation feeding real-time dashboard charts for First Response Time, Resolution Time, and Escalation Rate
    • Support analytics flow executing nightly to calculate team performance metrics from completed cases
  • Email Integration & Communication
    • Email-to-case integration via Salesforce Email Service capturing inbound support channel emails and creating linked case records
    • Outbound email templates attached to case updates with case details and KB article links merged as Salesforce template fields

Technical Details

Validation & Business Logic

  • CaseRequiredFields - Subject and Description cannot be blank OR empty
  • PriorityValidation - Case.Priority IN ('Low', 'Medium', 'High', 'Critical')
  • LocationMandatory - For Hardware/Network cases, Metro field is required (Picklist values: DC5, NY9, SJ1, etc.)
  • SLAEligibility - Only Acme Corporation account (AccountId = '001xx000000xxx') receives SLA terms
  • DescriptionMinLength - Description must contain minimum 10 characters
