Design Specs

Summary

Displays training courses in a scannable grid layout with real-time progress tracking and learning path visualization. Partners easily navigate course options, resume in-progress work, and monitor certification readiness through status-based filtering and visual completion indicators.

Jobs to Be Done

  • View all assigned training courses and status
  • Track progress toward tier certification requirements
  • Resume in-progress courses quickly
  • Filter courses relevant to role or interests
  • Understand course difficulty and time commitments
  • Plan learning path toward tier advancement

Design Specification

Primary Content

  • Training progress KPIs showing required/elective completion counts
  • Overall completion percentage with progress bar
  • Learning path timeline showing sequential module status
  • Multi-tab interface for Required, Elective, Completed, and Expired courses
  • Course cards in responsive grid with icon, title, badges, metadata, progress bar, and actions

Interactive Elements

  • View toggle between table, card, and kanban layouts
  • Tab switching to filter courses by status
  • Sort dropdown for course title, duration, or date
  • Search input to filter courses by keyword
  • Action buttons for Start Course, Resume, View Certificate, Re-enroll, or Enroll
  • Color-coded left borders on cards indicating completion status
  • Inline progress bars for in-progress courses

Functionality

  • Tab & Content Filtering
    • Tab switching toggles visible course cards without page reload based on course status
    • Sort dropdown reorders grid by title, duration, or date using Salesforce record queries
    • Search input dynamically filters courses by keyword matching course name and metadata
  • Progress Calculation & Aggregation
    • Progress calculations sum completed required and elective courses against totals from Salesforce
    • Overall completion percentage auto-calculates as (completed courses / total courses) × 100
    • Learning path markers update when course status changes in the backend database
  • Status-Driven Action Updates
    • Course status transitions trigger action button changes (Start, Resume, Re-enroll, View Certificate)
    • Due date comparisons highlight overdue courses with red border styling and opacity
    • Card border colors reflect status: green (Completed), yellow (In Progress), red (Expired), gray (Not Started)
  • Navigation & Integration
    • Action links route to course detail pages or enrollment workflows via course ID parameters
    • Resume button returns user to last accessed module position for in-progress courses

Technical Details

Validation & Business Logic

  • Required courses must be completed before certification eligibility
  • Expired courses must be re-enrolled within 30 days
  • Progress cannot exceed 100%
  • Due date must be in future for active courses
