Design Specs

Summary

Training content search results with best match promotion and certification path awareness, helping partners quickly resume courses and understand learning prerequisites for tier advancement.

Jobs to Be Done

  • Resume in-progress course with minimal clicks
  • Find related courses in the learning path
  • Understand certification prerequisites and paths
  • See course prerequisites and corequisites
  • Access battle cards and supplemental materials
  • Track progress toward certifications

Design Specification

Primary Content

  • Best match banner with course recommendation
  • Featured course card with resume or start option
  • Courses section with progress indicators
  • Certification path information and prerequisites
  • Related resources and battle cards
  • Locked state indicators for restricted courses

Interactive Elements

  • Resume or Start CTA button on featured course
  • View course details and syllabus
  • Filter by content type, difficulty
  • Apply "my courses" status filter
  • Click course cards to enroll or continue
  • View certification requirements and paths

Functionality

  • Best Match Detection & Promotion
    • Best Match banner displays when search query exactly matches Course__c.Title field and user has not completed the course, floating above main results
    • Featured course card (left border + tinted background) shows in results section while appearing in banner for context switching between discovery and learning
  • Course Progress Tracking & Persistence
    • Progress bars dynamically calculate from Course_Enrollment__c.Completion_Percent__c field and update in real-time as user progresses through SCORM modules
    • Resume Course button redirects to SCORM course module with completion state persisted via Course_Enrollment__c.LastAccessed__c timestamp, enabling seamless resume functionality
  • Prerequisite & Enrollment Validation
    • Locked state courses detected when prerequisite courses not yet completed, blocking enrollment and showing lock icon + "Locked" status indicator
    • Certification cards show prerequisite count (e.g., "1 of 2 prereqs") and completion progress bar, linked to Certification_Path__c object via Course__c junction table
  • Advanced Filtering & Faceted Search
    • Sidebar filters (Content Type, Category, Difficulty, My Status) AND-combined to refine results, with counts updating via AJAX without page reload
    • My Status filter reflects user's enrollment status: In Progress, Not Started, Completed — enabling personalized learning path filtering
