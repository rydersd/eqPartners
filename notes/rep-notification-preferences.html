Design Notes

Summary

Centralized control panel for managing notification delivery preferences across channels, categories, and times. Partners customize which alerts they receive via in-app and email, configure quiet hours and digest settings, and control notification volume across their entire user profile.

Jobs to Be Done

  • Control which notification categories are delivered via in-app and email
  • Set do-not-disturb hours to pause email notifications outside business hours
  • Opt-in to daily digest to consolidate multiple notifications
  • Pause weekend notifications to reduce noise
  • Configure timezone-aware quiet hours
  • Reset all preferences to organization defaults
  • View category-level descriptions to understand notification purpose

Design Specification

Primary Content

  • Page title with Save Changes action in header
  • Per-category preference cards: Deal Registration, Commissions, Training, Partner Success Manager, System & Announcements
  • Each card contains a table of notification types with toggles for In-App and Email delivery channels
  • Quiet Hours configuration section with start/end time inputs, timezone selector, and weekend pause toggle
  • Email Digest section with enable toggle and delivery time selector
  • Form footer with Reset to Defaults and Save Changes buttons

Interactive Elements

  • Toggle switches for each notification type per delivery channel (In-App, Email)
  • Time picker inputs for Quiet Hours start and end times
  • Timezone dropdown with timezone options
  • Weekend pause toggle checkbox
  • Daily Digest enable/disable toggle with delivery time selector dropdown
  • Save Changes button to persist all preferences
  • Reset to Defaults button to restore organization defaults
  • Breadcrumb navigation back to Notifications page

Functionality

  • Preference Storage & Synchronization
    • User preferences stored as Custom Settings or Custom Metadata records on User object in Salesforce
    • Save Changes button validates and persists all toggle states to user profile asynchronously
    • All changes sync across user's devices and sessions via Salesforce APIs
  • Channel-Specific Delivery Controls
    • In-app toggles control whether Custom Notifications are sent to user's notification center
    • Email toggles control whether email alert actions are triggered for each notification type
    • Validation enforces at least one delivery channel enabled per notification type
  • Quiet Hours & Scheduling
    • Quiet Hours logic implemented via Flow or Apex: email actions check quiet hours window before sending
    • Queued messages scheduled for delivery after quiet hours end time using time-based workflows
    • Weekend pause flag prevents any email delivery on configured weekend days via conditional logic
    • Timezone offset calculated server-side for accurate quiet hours window using user's selected timezone
  • Email Digest & Aggregation
    • Daily Digest uses scheduled Apex or Flow to aggregate notification records and send single summary email
    • Digest delivery time validated against user's timezone before scheduling
  • Reset & Defaults
    • Reset to Defaults restores organization-level default preferences defined by PCP admin

Technical Details

Validation & Business Logic

  • Preferences backed by Salesforce CustomNotificationType metadata for notification type definitions
  • Timezone offset calculated server-side for accurate quiet hours window
  • Digest delivery time validated against user's timezone
  • At least one delivery channel required for each notification type (prevents disabling all channels)
