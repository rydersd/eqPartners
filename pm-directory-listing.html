Summary

Partner-facing editor for the equinix.com Partner Finder directory listing. PCP is the single source of truth — this page is where partners manage their public-facing presence without needing to contact marketing or submit a separate request.

Data Model

  • Auto-synced (read-only in UI): Company name (from D&B via Salesforce), tier badge, earned certifications. Partners contact PSM to dispute.
  • Partner-managed, immediate publish (<4h): Logo, tagline, description, website URL, CTA email, landing page URL.
  • Partner-managed, PSM review required (2–3 days): Solution areas, technology specializations, geographic regions. PSM validates before these appear as filterable attributes on the public directory.

Jobs to Be Done

  • Partner should never need to email marketing or submit a Jira ticket to update their directory listing
  • PSM should see review queue in their dashboard when solution areas / geo tags change
  • Tier and cert badges should reflect program reality without manual updates
  • Partner knows exactly what buyers see (live preview) without visiting the public site

Data Flow

  • PCP → Salesforce PRM → equinix.com directory (via API or scheduled export; target <4h propagation for immediate fields)
  • Tier / certs: sourced from program achievement data in Salesforce; write-back to PCP profile on change
  • Company name / firmographic: sourced from D&B lookup at onboarding; update only via PSM to prevent data drift
  • PSM review queue: changes to solution areas / geo create a Salesforce task assigned to the partner's PSM

Industry patterns

  • AWS Partner Network: APN profile in Partner Central is the source for the public Partner Finder. Competency badges appear within 24h of being earned. No separate marketing form.
  • HubSpot Solutions Directory: Tier (Gold → Elite) auto-reflects in directory. Partners manage description / specializations from within HubSpot Partner Portal. Editorial review before first publish only.
  • Salesforce AppExchange: Listing managed in Partner Community. Compatibility tags (clouds, industries) come from partner profile. Human review before each publish.
  • The review gate on solution areas is intentional — it prevents partners from gaming filters. AWS uses a similar model: competency badges require Equinix (or AWS) validation, not self-declaration.

Design Notes

  • Visual distinction between auto-synced (gray/locked), immediate (white), and review-gated (yellow badge) fields is the core UX affordance — partners must understand why some changes take longer
  • Preview panel is sticky at 300px to give persistent feedback as partner edits
  • Character counters on description fields match directory card truncation limits
  • Tech specialization tags are freeform (not filterable) — reduces PSM review burden while giving partners expressive latitude
  • Logo upload: display at 36px, require 200px source — prevents blurry logos without burdening partners with strict format rules
