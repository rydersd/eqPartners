Salesforce Objects & Fields (Certification Data)

Certification__c Object Fields
Cert_Name__c, Contact__c (lookup), Course__c (lookup), Issue_Date__c, Expiration_Date__c, Verification_Code__c (unique EQ-YYYY-II-NNNN format), Certificate_PDF__c (file), Status__c (Active|Expired), Track__c
Auto-Generation: Flow-Triggered
Triggered: Partner_Training__c Status='Completed' AND Has_Certification__c=true. Creates Certification__c with Issue_Date__c=TODAY(), Expiration_Date__c=TODAY()+[Course.Cert_Valid_Months__c] months. Generates unique Verification_Code__c. PDF generated async within 24 hours.
Validation: Cert Expiration Logic
Most certs valid 24 months (Course.Cert_Valid_Months__c=24). Technical certs may be 18 months. Expiration auto-calculated. Expired certs show in Expired tab. Re-certify button creates new enrollment.
Re-Certification Process
Expired cert "Re-certify" button creates new Partner_Training__c enrollment for same course. Requires full course retake (no partial renewal). Old cert audited. New Verification_Code__c issued on completion (sequence+1).

Error States & Accessibility & Validation

Error: "Certificate PDF not yet generated — check back in 24 hours" (async PDF generation). Error: "Verification link expired — re-download certificate".

Accessibility: Cert cards role='article' with aria-label. Track progress bars aria-valuenow/min/max. Status: icon + color + text (never color alone). Tab navigation uses aria-selected.

Validation: Cert auto-gen on completion. Code format EQ-YYYY-II-NNNN (unique). Expiration 2 years configurable per course. Re-cert = full retake. Tracks earned commissions at tier rate.

Design Specs

Summary

Displays partner rep's earned and expired certifications with expiration tracking, renewal options, and shareable credentials. Tracks progress toward tier-specific certification requirements.

Jobs to Be Done

  • View earned certifications with dates in centralized dashboard
  • Track expiration proactively to avoid tier impact
  • Renew certifications by re-enrolling and completing course
  • Share verifiable credentials with customers or employers
  • Understand certification path for next tier advancement
  • Monitor progress against tier-specific requirements

Design Specification

Primary Content

  • Summary stats: Active, Expiring Soon, Expired, Total certification counts
  • Certification Track Progress bars (Business 4/4, Technical 0/4)
  • Certification cards with title, track badge, issue/expiration dates, status badge
  • Expired certifications requiring renewal with grayed-out styling
  • Certification verification preview (sample certificate of completion)
  • Cert Paths sidebar (Foundation, Advanced tracks)
  • My Credentials sidebar (earned certs and progress toward next cert)

Interactive Elements

  • Tab filters (All, Active, Expiring Soon, Expired)
  • Download certificate PDF button
  • Share certification link for verification
  • Re-certify button for expired certifications
  • Activity and Agentforce AI recommendation tabs in right rail
  • View Certificate and Start Next Path action buttons

Functionality

  • Auto-Creation & Verification
    • Certification__c record auto-created via Flow trigger when Partner_Training__c.Status = 'Completed' AND Has_Certification__c = true
    • Verification_Code__c auto-generated in EQ-YYYY-II-NNNN format (e.g., EQ-2025-SC-00427); unique constraint prevents duplicates; sequence increments on re-cert
    • Contact__c and Course__c lookups automatically populated from enrollment parent record
  • Date Calculation & Expiration Logic
    • Issue_Date__c set to TODAY() on creation; Expiration_Date__c calculated as TODAY() + Course.Cert_Valid_Months__c (typically 24 months, 18 for technical)
    • Status__c auto-set to 'Expired' via daily batch/scheduled flow when current date exceeds Expiration_Date__c
    • Expiration tracking dashboard: count of active vs. expired certs updated nightly
  • Asset Generation & Renewal
    • Certificate PDF generated asynchronously within 24 hours via Flow action or batch process; stored in Certificate_PDF__c file field
    • Re-certify button creates new Partner_Training__c enrollment for same course (full retake required); original cert retained for audit trail with new sequence code
    • PDF download link validated; expired links trigger new PDF generation on request
  • Progress Tracking & Tier Management
    • Track progress calculated as COUNT(Certification__c WHERE Track__c='Business' AND Status__c='Active') / tier_requirement (e.g., 4/4 for Business)
    • Dashboard summary dynamically filters certs: Active (Status='Active'), Expiring Soon (due <90 days), Expired (Status='Expired')

Technical Details

Salesforce Objects & Automation

  • Certification__c custom object with Cert_Name__c, Contact__c (lookup), Course__c (lookup), Issue_Date__c, Expiration_Date__c, Verification_Code__c, Certificate_PDF__c (file), Status__c, Track__c fields
  • Flow-triggered on Partner_Training__c Status='Completed' AND Has_Certification__c=true
  • Validation rule enforces Verification_Code__c unique + format compliance (EQ-YYYY-II-NNNN)
  • Batch or scheduled flow runs daily to update Status__c='Expired' for records past expiration
  • PDF file link expires after configurable period; re-download triggers new PDF generation
