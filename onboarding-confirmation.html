Design Specs

Summary

Application submission confirmation page providing receipt confirmation, reference ID, and transparent timeline for next onboarding steps while reducing applicant anxiety through clear progress visibility.

Jobs to Be Done

  • Confirm that application was received successfully
  • Provide applicant with unique reference ID for status tracking
  • Show exactly what confirmation email was sent
  • Set expectations for timeline and next steps in process
  • Reduce applicant anxiety with clear progression visibility

Design Specification

Primary Content

  • Step indicator showing Steps 1-5 with Step 2 active and completed badge
  • Success confirmation card with application ID, partner type, and submission date
  • Email confirmation preview showing exactly what was sent to applicant
  • What Happens Next timeline with 4 remaining steps and current-step animation
  • Contact information for application questions and support

Interactive Elements

  • Step indicator visually shows onboarding progress with completion checkmarks
  • Email and phone contact links for support with click-to-call capability
  • Timeline shows expected timing for each onboarding phase with pulsing current step

Functionality

  • Public Access & Authentication
    • Public access URL (no login required) using Lightning Community guest user access via shared URL parameter ?applicationId={!Partner_Application__c.Id} validated against public record link whitelist
    • Guest page access via Salesforce guest user profile with record access enforced through SOQL WHERE clause filtering by specific Application_ID__c value from URL parameter
    • Return link to log in with AccountLink__c stored on Partner_Application__c redirecting authenticated user to partner portal
  • Email Management & Archival
    • Server-side email generation triggered by after-insert Apex trigger on Partner_Application__c calling Messaging.sendEmail() with confirmation template
    • Email template merging Partner_Application__c fields including Contact Name, Company Name, and Application_ID__c into template body
    • Email archival storing sent email in EmailMessage object linked to Partner_Application__c via automatic Salesforce email integration for audit trail and future reference
  • Timeline & Milestone Tracking
    • Automatic timeline calculation based on Partner_Application__c.Application_Date__c field using formula field Partner_Onboarding_Task__c.Days_Remaining__c = Expected_Completion_Date__c - TODAY()
    • Stage milestones populated on child Partner_Onboarding_Task__c records via Flow Orchestration executing after Partner_Application__c status transition to 'Submitted'
    • Expected completion dates calculated using Stage_Duration_Days__c custom field multiplied by stage index providing 7, 14, 21, 30 day targets
  • Status Display & Real-Time Updates
    • Real-time pipeline stage display synced from Partner_Application__c.Pipeline_Stage__c field using Visualforce page refresh every 60 seconds via page polling mechanism
    • Stage indicator component rendering step-by-step progress bar with checkmark icons for completed stages and current stage highlighted with pulsing animation CSS
    • Status text updating from Partner_Application__c picklist values ('Submitted', 'Under Review', 'Approved', 'Agreement', 'Fully Activated')
  • Engagement & Support
    • Contact links for PSM support embedded with SOQL query lookup fetching Partner_Service_Manager__r.Phone__c and Email__c from related Partner_Service_Manager__c record
    • Click-to-call capability on phone number link using anchor tag and SMS capability using href="sms:+1234567890"

Technical Details

Key Objects

  • Partner_Application__c (Status = 'Submitted', Application_Date__c, Application_ID__c)
  • EmailMessage — Captured confirmation email for display and audit trail
  • Partner_Onboarding_Task__c — Child records defining timeline stages and expected completion dates
