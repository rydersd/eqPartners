Design Notes

Summary

Step 1 of the Deal Registration wizard in Partner Central. Jordan Reeves (portal admin / sales ops at CloudBridge) selects the relationship type — Lead Referral Partner or Reseller — that governs how this specific deal is being registered. This is separate from Partner Organization Registration (how a company joins the Equinix partner program). The Deal Registration Matrix helps the user self-qualify before proceeding.

Figma Source

  • File: Partner-Central
  • Node: 2662:12994
  • Frame: "00 Deal Type / Deal Registration P1 – Prospect"

Flow Position

  • Flow: Deal Registration wizard — Step 1 of 5
  • Triggered from: Partner Central Home → Register a Deal (or Deals & Opportunities → New)
  • Next: pc-dr-p2-prospect.html (Prospect Details)
  • Referral selected → Lead Referral Partner deal registration flow
  • Resale selected → Reseller deal registration flow
  • Note: Separate from Partner Organization Registration (the onboarding flow for new partner companies joining the program)

Jobs to Be Done

  • Help the partner self-select their engagement model (Referral vs. Resale)
  • Surface the decision matrix so partners can confirm they're choosing correctly
  • Route to the correct deal registration form based on selection

Design Specification

Primary Content

  • Page title: "Deal Registration" with supporting sub-copy
  • Intro paragraph explaining Referral vs. Resale and pointing to the matrix for self-qualification
  • Two relationship-type cards: Lead Referral Partner and Reseller (radio behavior)
  • Each card shows: tagline, You / Equinix / Best when rows
  • Deal Registration Matrix — 11-row decision table (Decision Question | Referral | Reseller) for self-qualification
  • Register CTA button (right-aligned, primary)

Interactive Elements

  • Relationship-type cards act as radio group — selecting one deselects the other
  • Cards are keyboard-accessible (Enter / Space activates; focus ring visible)
  • Notes sidebar toggle button (fly-in spec panel)
  • Register button — advances to Step 2 (Prospect Details), carrying the selected relationship type

Functionality

  • Card Radio Selection — mutual exclusion via aria-checked and role="radio"; Referral selected by default per Figma spec
  • Deal Registration Matrix — informational only; no form input on this step
  • Register — passes selected relationship type to the next wizard step; ideally disabled until a card is explicitly chosen (Referral pre-selected counts as chosen)
  • Keyboard nav — Enter/Space fires selectCard() for each card

Design Notes

  • Referral card shown selected by default (per Figma spec)
  • Card selection persists into next wizard step
  • Deal Registration Matrix is a decision table — not a form element
  • Partner Central uses white header + Nexa typeface (Figma); wireframe approximates with system font
  • Header nav shows only "Home" at this stage — expanded once partner type is confirmed
