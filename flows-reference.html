Process Flows End-to-end journeys across multiple screens and actors

Emergency Escalation → Executive Brief →
Dispute detected → PSM creates escalation → Agentforce generates brief → VP call scheduled → resolution. 6 actors, 8 steps.
Deal Registration Lifecycle →
Rep submits DR → system validates → PSM approves → protection window starts on approval date → pipeline tracked → Deal Desk qualifies commission → close-out. 5 actors, 7 steps.
MDF Lifecycle →
Partner requests MDF → PSM reviews eligibility → PAM approves budget → partner executes activity → claim submitted with proof → PAM verifies → Finance reimburses. Dispute branch included. 4 actors, 7 steps.
Partner Onboarding Journey → (see above)
Pre-auth → application → agreement → provisioning → Day-0 orientation → active selling. Fully wired above.
Tier Review Cycle →
System triggers annual eval → PSM reviews health scorecard → PAM authorizes tier change → 3 outcome paths (upgrade / maintain / downgrade) → partner notified → optional 30-day appeal → tier change on renewal date. 4 actors, 8 steps.
Joint Business Plan Creation → (planned)
PSM + Partner Executive co-create JBP → goals set → commitments signed → quarterly check-in cycle. Addresses exec-level blind spot.
Wired: Emergency Escalation Brief · Deal Registration Lifecycle · MDF Lifecycle · Tier Review Cycle — full cross-actor swimlane diagrams. Planned: JBP Creation flow — stub defined, diagram pending.
