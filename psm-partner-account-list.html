Design Specs

Summary

Displays the complete portfolio of partner accounts with training completion and tier advancement status. Stark Industries (Gold, $180K MRR, 95% trained) is highlighted as a near-win partner close to Platinum tier. PSMs use this list view as their daily dashboard to identify accounts needing engagement and support.

Jobs to Be Done

  • Scan full partner portfolio for accounts needing attention on training/advancement
  • Identify near-win and at-risk partners via visual highlighting
  • Send personalized encouragement messages to Partner Managers without leaving list
  • Default landing page for PSMs—starting point each morning
  • Support tier advancement tracking and engagement workflows

Design Specification

Primary Content

  • Stacked bar chart showing partner distribution by tier (Gold, Silver, Bronze, Registered)
  • Completion distribution chart (0-25%, 26-50%, 51-75%, 76-100%)
  • Data table with 12 partner accounts per page (42 total)
  • Columns: Account Name, Tier, Team Size, Completion %, Courses to Next, Overdue, Region, Last Activity, Actions
  • Near-win rows highlighted with dark left border (95%+ completion)
  • At-risk rows highlighted with red left border (low completion or overdue courses)

Interactive Elements

  • View selector dropdown (All Partners, My Accounts, Near-Wins Only, At-Risk)
  • Removable filter pills (IsPartner = True, My Accounts)
  • Encourage quick action link on each row
  • Clickable account name navigates to Account Record page
  • Column header sort controls
  • New Account, Refresh, and Settings buttons
  • Select all checkbox and row-level checkboxes for bulk operations
  • Previous/Next pagination controls

Functionality

  • Partner Account Filtering & Sorting
    • Filter Account records to show only accounts where IsPartner__c = true and OwnerId matches current PSM user
    • Default sort by Courses_To_Next_Tier__c ascending to display closest-to-advancement partners first
    • Apply Status filters to show All, Active, Inactive, or Churned partners based on Account_Status__c field
  • Near-Win & At-Risk Classification
    • Calculate Near-win status using formula: (Partner_Tier__c != 'Gold') AND (Completed_Requirements__c / Tier_Threshold__c) >= 0.95
    • Identify at-risk partners using logic: (Completion_Percentage__c < 50%) OR (Overdue_Courses_Count__c > 0)
    • Display status badges to highlight accounts needing immediate PSM attention or encouragement
  • Progress Visualization & Status Indicators
    • Display progress bar with dynamic coloring: red (0-49%), amber (50-74%), green (75-100%)
    • Show Overdue badge only when Overdue_Courses_Count__c > 0 with count of past-due required courses
    • Render partner tier status and points toward next tier advancement with distance indicator
  • Encouragement Workflow & Communication
    • Trigger "Encourage" action which opens modal to compose and send pre-templated message to partner manager
    • Log encouragement activity to Partner_Communication_History__c with timestamp and message template used
    • Integrate with Account_Contact_Relationship to identify correct manager contact for messaging
  • Account Management & Bulk Operations
    • New Account button opens account creation form pre-populated with Record Type = Partner
    • Select all checkbox and row-level checkboxes enable bulk account actions (reassign, tag, export)
    • Quick links navigate to partner account detail page for individual management and full scorecard view
