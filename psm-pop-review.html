Design Specs

Summary

Enables PSMs to systematically review and approve Proof of Performance claims from partners before routing to finance for MDF reimbursement. Validates campaign metrics against planned targets and verifies supporting documentation compliance.

Jobs to Be Done

  • Systematizes PoP review workflow with clear metrics validation and compliance checks
  • Compares planned vs actual campaign performance (leads, impressions, attendance, cost per lead) to assess MDF ROI
  • Enables document review of supporting evidence (receipts, invoices, event photos, screenshots) for audit compliance
  • Tracks review turnaround time (avg 2.1 days) and maintains audit trail of approval decisions
  • Routes approved claims to finance for payment processing with reimbursement calculation

Design Specification

Primary Content

  • KPI summary cards: Pending Reviews count, Approved This Month amount, Average Review Time
  • PoP Submissions table with Campaign Name, Partner, Submitted Date, Budget, Status columns
  • Metrics Validation card for selected campaign: Planned vs Actual comparison for Leads Generated, Impressions, Event Attendees, Cost per Lead with variance indicators
  • File Attachments list showing Campaign Report PDF, Analytics Dashboard Screenshot, Receipts/Invoices ZIP, Event Photos ZIP with View links
  • Review Decision section with PSM assessment narrative and three action buttons (Approve, Request Documentation, Reject)
  • Review Notes textarea for internal documentation of approval rationale
  • Activity/Einstein right rail showing submission timeline and AI recommendation on metrics

Interactive Elements

  • Filter dropdowns for Status (All, Pending, Approved, Rejected) and Month selector
  • Clickable table rows to select campaign and load detailed metrics validation view
  • Approve PoP → Trigger Reimbursement button initiating payment workflow to finance
  • Request Additional Documentation button to send info request notification to partner
  • Reject button to decline claim with documented reason
  • View links on attachment items to open/download supporting documentation
  • Activity/Einstein tab toggle in right rail

Functionality

  • PoP Submission Retrieval & Filtering
    • Queries all MDF_PoP_Submission__c records for current org, filters by Status (Pending, Approved, Rejected) and submission month using picklist dropdowns
    • Table displays Campaign Name, Partner Account link, Budget Allocated (MDF), Submitted Amount, Status badge, with row-level click handler
  • Metrics Validation & Variance Calculation
    • Clicking table row loads Campaign_Metrics__c child records with Planned vs Actual comparison: Leads Generated, Impressions, Event Attendees, Cost per Lead
    • Formula calculates variance percentage: ((Actual - Planned) / Planned) * 100; displays red badge if <90%, yellow if 90-99%, green if 100%+ achievement
  • Supporting Documentation Review
    • ContentDocument query retrieves all attachments linked to MDF_PoP_Submission__c via ContentDocumentLink; displays Campaign_Report_Feb2024.pdf, Analytics_Dashboard_Screenshot.png, Receipts_and_Invoices.zip, Event_Photos_Album.zip with view/download links
  • Automated Scoring & Review Decision
    • Einstein AI recommendation evaluates Campaign_Metrics__c variance and documentation completeness to return approval confidence score and strategic fit recommendation text
    • Displays validation summary and Einstein recommendation in Review Decision section to guide PSM decision
  • Approval & Payment Routing Actions
    • Approve button creates Reimbursement_Request__c record with submitted amount, sends Salesforce email alert to finance team, and logs approval_timestamp__c + approver__c to audit trail
    • Request Documentation action sends email template to Partner contact with specific missing document requirements list and 5-day deadline
    • Reject button updates MDF_PoP_Submission__c.Status__c to 'Rejected', captures rejection_reason__c in Review Notes, creates PoP_Review_Notes__c child record, notifies partner and finance via workflow email
