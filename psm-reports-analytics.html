Design Specs

Summary

Centralized reporting and analytics hub providing pre-built and custom reports on partner program performance including training completion, revenue, MDF utilization, and onboarding pipeline. Featured report: Stark Industries performance snapshot (Gold tier, $180K MRR, 95% training completion, 5 active deals, near-Platinum status). Supports scheduled report delivery to stakeholders and ad-hoc data exports.

Jobs to Be Done

  • Provide centralized access to all program reporting and analytics
  • Support data-driven decision making with multiple pre-built reports
  • Allow custom report creation for specific analysis needs
  • Enable automated report delivery to stakeholders on schedule
  • Surface key metrics and trends across training, revenue, and program health

Design Specification

Primary Content

  • KPI header cards: Total Partners, Average Completion %, Program Health Score, Revenue Attainment %
  • Tabbed interface with four sections: Training Reports, Revenue Reports, Program Health, Scheduled Reports
  • Training Reports tab: 4 report cards (Course Adoption, Certification Completion, Training Timeline, Team Progress by Course) with View Report and Schedule Delivery buttons
  • Revenue Reports tab: 4 report cards (Partner Revenue Growth, Deal Pipeline, Commission Analysis, Co-Market ROI) with View Report buttons
  • Program Health tab: 4 report cards (Partner Engagement Score, Onboarding Pipeline, MDF Utilization, JBP Progress) with charts and View Report buttons
  • Scheduled Reports tab: Table of active/scheduled reports showing name, cadence, recipients, last/next run, status

Interactive Elements

  • Tab navigation buttons switching between Training, Revenue, Program Health, Scheduled Reports
  • Report cards expandable to show full details and embedded charts
  • Export CSV button in report headers for data export
  • View Report button on each card to open full report view
  • Schedule Delivery button to set up automated report email distribution
  • Filter controls: Date Range selector, Partner Tier dropdown, Region dropdown
  • New Scheduled Report button in Scheduled Reports tab
  • Edit button on scheduled report rows to modify delivery schedule/recipients
  • Apply Filters button to execute filtered report views

Functionality

  • KPI Aggregation & Caching
    • KPI header cards pull from cached aggregate views (Platform Cache or Aggregate Result) updated daily: Total Partners (COUNT Account), Average Completion % (AVERAGE Completion_Percentage__c), Program Health Score (AVERAGE Health_Score__c), Revenue Attainment % = (Revenue_This_Year / Revenue_Target) * 100
    • Displays trend indicators showing period-over-period change with color coding
  • Training & Revenue Reports Generation
    • Training Reports cards query Partner_Training__c, Certification__c, Partner_Scorecard__c records with filters: date range (Date_Completed__c), Partner_Tier__c selection; generates Course Adoption, Certification Completion, Training Timeline, Team Progress by Course reports
    • Revenue Reports cards query Opportunity, Deal_Registration__c with Account grouping; displays top 10 partners revenue table with SUM(Amount) and commission calculations (Amount * Commission_Rate__c)
  • Program Health & Onboarding Analytics
    • Program Health Reports aggregate Partner_Scorecard__c.Engagement_Score, Partner_Onboarding__c stage counts (grouping by Stage__c), MDF_Budget_Allocation__c spend % (SUM Paid / SUM Allocated), Joint_Business_Plan__c status counts
    • Renders cards with embedded charts showing trend visualization
  • Export & Data Sharing
    • Export CSV button generates downloadable file with report data respecting Salesforce sharing model: PSMs see only owned Account records, Admins see all accounts; limits export to 10K rows with notification for larger datasets
  • Report Scheduling & Custom Reporting
    • Schedule Delivery action creates Report_Schedule__c record and triggers Flow to send email on selected cadence (weekly, monthly, quarterly) to specified recipient list
    • Scheduled Reports table displays active Report_Schedule__c records with Next Run timestamp calculated from cron expression, Last Run timestamp, and report status
    • Custom Report Builder enables users to select data source (Partner_Scorecard__c, Opportunity, Partner_Training__c), columns, filters (date range, tier, region), and grouping (by Account, by Tier, by Month)
    • Report caching: Standard reports cached up to 24 hours via Platform Cache; real-time flag bypasses cache for up-to-the-minute data delivery

Technical Details

Validation & Business Logic

  • Report (standard): Standard Salesforce reporting on Opportunity, Contact, Partner_Training__c, Jo...
  • Dashboard (standard): Custom Dashboards with components for KPIs, training progress, revenue trend
  • Partner_Scorecard__c (custom aggregate): Partner_Account__c, Training_Completion_Pct__c, Revenue_...
  • CRM Analytics dataset (Tableau): Read-only views for training and revenue trends
  • Reports respect sharing rules — PSM sees only owned accounts unless admin
  • Export limited to 10K rows (use async export for larger datasets)
  • Scheduled reports max 5 per user
  • Report caching: Max 24 hours old; refresh forced for real-time reports
  • Dashboard filters: User must have read access to filtered account
