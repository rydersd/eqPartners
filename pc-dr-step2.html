Design Notes

Summary

Step 2 of the Deal Registration wizard. Jordan Reeves enters deal specifics: distributor, deal type, partner project code, IBX locations (dual listbox with region filter), primary and additional Equinix services, a deal description, optional file uploads, and alliance partners. Prospect name is surfaced in the hero context bar for continuity.

Flow Position

  • Previous: pc-dr-step1.html (Prospect Information)
  • Next: pc-dr-step3.html (Sales Contact)

Design Decisions

  • Region radio + dual listbox — Region pill filters the available IBX list. User moves locations to the selected column. Familiar pattern from the live Equinix Partner Central product.
  • Alliance partner listbox — Optional. Pre-populated with common cloud/tech alliance partners. Empty by default.
  • Context bar — Prospect name added to the hero context row so users maintain orientation across steps
  • AI rail — Will surface service recommendations and IBX suggestions based on company profile in a future release

Form Fields

  • Distributor — optional dropdown
  • Deal Registration Type — required dropdown (New Business, Expansion, Renewal, Migration)
  • Partner Project Code — optional text
  • Locations — required; region radio filter + dual listbox
  • Primary Services — required; checkboxes
  • Additional Services — optional; checkboxes
  • Description — required; textarea, min 50 chars
  • Supporting Documents — optional; file upload
  • Alliance Partners — optional; dual listbox
