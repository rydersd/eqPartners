PAM Portal · Alex Rivera · Executive Program Report

Job to Be Done

"When building the quarterly program report, I want a single view of MDF efficiency, partner-sourced revenue, and tier health — so I can defend program spend to leadership and surface which investments are actually driving results."

Screen Purpose

Alex's executive-facing reporting screen. The audience is partly Alex herself (she uses this to monitor program health) and partly Equinix leadership (she exports this as a PDF for quarterly business reviews). The data needs to answer: Is the MDF program worth the investment? Which tiers and activity types are delivering?

Key Design Decisions

  • ROI as the headline metric — 34.9x program ROI is the number leadership cares most about; it leads the KPI row
  • Cost per $1 of ARR by tier — this is the efficiency metric that shows Gold partners are cheaper to generate revenue from (more scale per MDF dollar), which justifies the Gold-tier allocation model
  • Activity type ROI table — helps Alex optimize future allocations; Training looks weak on ROI but the spec note explains the lag effect
  • Export to PDF button — this report is primarily built for executive presentation; PDF export is a primary CTA
  • Tier movement summary paired with open reviews — connects program dynamics (who's moving up/down) with the near-term action list (who needs attention this quarter)

Data Model

  • Partner-Sourced ARR: sum of Opportunities with Stage = Closed Won, Partner_Account__c populated, Close_Date__c in current fiscal year
  • Program ROI: total partner-sourced ARR / total MDF paid; also broken out by tier and activity type
  • MDF utilization = Spent / Allocated per tier (aggregated from MDF_Allocation__c)
  • Tier movement: count of Tier_Change_History__c records by type (Upgrade/Demotion) and fiscal quarter
