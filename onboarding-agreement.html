5. TERM & TERMINATION

5.1 This Agreement is effective for an initial term of one (1) year and shall automatically renew for successive one-year periods unless terminated by either party with sixty (60) days written notice.

5.2 Equinix may terminate this Agreement immediately upon material breach by Partner.

Design Specs

Summary

Agreement presentation and e-signature page allowing authorized partners to review, sign, and accept partner program terms via DocuSign with full audit trail and compliance tracking.

Jobs to Be Done

  • Present legally binding partner program agreement
  • Capture partner signature via DocuSign with audit trail
  • Verify partner authorized to sign on behalf of company
  • Record agreement acceptance and compliance with terms
  • Enable automated countersign workflow after partner signs

Design Specification

Primary Content

  • Approval banner confirming application was approved
  • Approval email mockup showing application ID and company name
  • Partner Program Agreement document with scrollable preview
  • Agreement header with download and print actions
  • Signature section showing signed status with timestamp and IP address
  • Terms acceptance checkboxes confirming understanding and authorization

Interactive Elements

  • Download agreement as PDF for records
  • Print agreement if needed
  • Sign via DocuSign or type/draw signature
  • Accept terms checkboxes before submission
  • Submit Signed Agreement button to proceed to confirmation page

Functionality

  • E-Signature & Document Management
    • DocuSign integration creating envelope via API call to DocuSign REST API with partner signer role pre-populated from Partner__c.Signer_Email__c field
    • Document embedding storing Partner Agreement PDF as DocuSign document source with tab markers (signature, date, initial tabs) from DocuSign template configuration
    • Redirect link generation receiving DocuSign ceremony URL from API response and redirecting iframe to DocuSign embedded signing experience
  • Form Validation & Compliance
    • Client-side signature validation using JavaScript event listeners requiring all checkbox inputs (Confirm_Terms__c, Confirm_Authority__c) to be checked before enabling Submit button
    • Prevent form submission by attaching onsubmit handler returning false if validation fails and displaying error message alert
    • IP address and timestamp logging capturing request.getClientIp() in Node backend middleware and storing in Partner_Agreement__c.Signer_IP__c and Signed_Date__c fields
  • Record Creation & Audit Trail
    • Server-side creation of Partner_Agreement__c record via Apex HTTP callout triggered by POST /api/create-agreement endpoint receiving DocuSign envelope completion webhook
    • Signature metadata extraction parsing DocuSign webhook payload accessing docusign.envelopeId, completedDateTime, and recipient email fields
    • Document versioning tracking with Partner_Agreement__c.Version__c field incrementing on each amendment and Document_Status__c picklist showing 'Draft', 'Partner Signed', 'Fully Executed'
  • Notification & Workflow
    • Automated notification workflow triggered via after-insert Apex trigger on Partner_Agreement__c sending Messaging.sendEmail() call to Equinix_Legal_Queue__c with envelope details
    • Countersign initiation email including DocuSign envelope ID and partner signer information stored in custom email template field Partner_Agreement__c.Countersign_Email_Body__c
    • Case creation for Legal team via Process Builder when Partner_Agreement__c.Status__c = 'Partner Signed' assigning to Legal_Team_Queue__c with priority High

Technical Details

Key Objects

  • Partner_Application__c (Status = 'Agreement')
  • Partner_Agreement__c (new record created on signature with Signed_Date__c, Signer_Name__c, Signer_IP__c, DocuSign_Envelope_ID__c)
  • DocuSign Envelope — Linked via DocuSign_Envelope_ID__c for audit trail access
