Design Notes

Summary

Integrated support center combining FAQ search, knowledge base discovery, support case submission/tracking, and direct PSM contact access. Enables partners to self-serve or escalate issues efficiently.

Jobs to Be Done

  • Find answers to common partner program questions
  • Submit and track support requests
  • Access program documentation and guidelines
  • Connect with PSM for strategic support
  • Self-serve resolution for common issues

Design Specification

Primary Content

  • Support center with FAQ categories and keyword search
  • Knowledge base article previews with relevance ranking
  • Open support case list showing status, priority, and SLA timers
  • New support ticket submission form (category, priority, subject, description, attachments)
  • PSM contact card with name, role, email, and scheduling link
  • Program documentation and guidelines quick-access links
  • Sidebar with support hours and chat availability indicator

Interactive Elements

  • Search knowledge base articles by keyword
  • Browse and filter FAQ by category
  • Submit new support ticket with file attachments
  • View ticket status, priority, SLA remaining time, and update history
  • Click PSM contact to email, call, or schedule meeting
  • Initiate live chat support session
  • Download program documentation and guidelines

Functionality

  • Knowledge Base Search & Retrieval
    • Query Knowledge__c articles and rank by popularity and LastModifiedDate for relevance
    • Full-text search articles and FAQs indexed on title, body, and keywords for keyword matching
    • Filter and display only published articles where Published__c = True
  • Case Submission & Routing
    • Create Case object from ticket submission form with category, priority, and subject validation
    • Auto-assign to support queue based on Case Category__c picklist selection
    • Attach uploaded files to Case record and validate file type and size limits
  • PSM & Contact Management
    • Retrieve related Account PSM via AccountTeamMember lookup for display in contact card
    • Display PSM contact information and scheduling links for direct communication
    • Update PSM assignment when Account team member changes
  • SLA Tracking & Support Workflow
    • Calculate and display SLA_Time_Remaining__c with visual indicators (on-track/at-risk/breached)
    • Track case history and auto-email customer on status changes via workflow rules
    • Escalate cases automatically when SLA thresholds are breached based on priority level
    • Integrate ChatBot widget for instant support routing and intelligent triage

Technical Details

Validation & Business Logic

  • Case submission requires category, priority, subject validation
  • File attachments limited to PDF, DOC, DOCX, XLSX (max 25MB per file)
  • Auto-assign to support queue based on Case Category__c picklist
  • SLA tracking based on Priority; escalate if breached
  • Only display articles with Published__c = True
