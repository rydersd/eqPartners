Design Specs

Summary

Post-activation orientation screen. The user arrives here already authenticated — they just set their password on partner-set-password.html. No org data exists yet beyond the signed agreement. This page orients them to Partner Central and offers two paths: start the setup wizard or go straight to the dashboard.

Flow Position

Application chain: Apply → Confirmation → Verification → Agreement → Activate Account (partner-set-password.html) → Welcome (this page) → Onboarding Wizard → Dashboard

Design Decisions

  • No "Log In" CTA. The user is already authenticated. The primary CTA launches the setup wizard. The secondary CTA goes directly to the dashboard.
  • No email mockup. Removed — the user arrived here by clicking a link in that email. Showing it again is confusing and redundant.
  • No account details card. No org data exists at this point — only the agreement is signed. Account details (tier, territory, commission rate) are populated after the wizard completes and the PSM configures the account.
  • No Channel Manager name inline. The PSM introduction happens in the wizard's Step 1 welcome banner, not on this page.
  • "Return to setup" note. Present in hero subtext to reassure skippers they can always come back.

Jobs to Be Done

  • Confirm enrollment is complete and account is active
  • Orient new partner to what the setup wizard covers (team, training, deals, marketing)
  • Offer two clear paths: start wizard now, or go to dashboard and return later
  • Surface partnership documents for download
  • Provide shortcuts to the main portal areas for early explorers

Return to Setup Pattern

After skipping, a persistent "Continue your account setup" banner appears on the Partner Home dashboard (rep-home.html). It shows wizard progress (e.g., "2 of 4 sections complete") and links back to onboarding-wizard.html. The banner is dismissable but accessible from My Account → Getting Started at any time.
