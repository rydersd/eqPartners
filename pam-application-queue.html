pam-application-queue.html

PAM Portal · Alex Rivera · Application Review Queue

Job to Be Done

"When a new partner application arrives, I want to assess fit and financial risk quickly, so I can make a tier decision within the 30-day SLA — and never let an overdue item stay unresolved."

Screen Purpose

Alex's primary daily view. Shows all open partner applications ranked by urgency (days-in-queue), with tier recommendations, compliance gaps, and risk flags surfaced in the table so she can triage without clicking into each record.

Key Design Decisions

  • Overdue rows highlighted in red — row-level color coding means Alex spots SLA breaches at a glance without reading the status column
  • Compliance dots pattern — four fixed-position dots (NDA / W-9 / Insurance / Credit) give a scannable compliance fingerprint per application; a single missing dot flags a blocker
  • Tier recommendation shown, not decided — the queue shows the auto-scored recommendation; Alex reviews and confirms in the detail screen
  • Days-in-queue as primary sort — default sort is by urgency, not submission date, because recency is irrelevant if an older application is at risk
  • D&B DUNS shown — surfaces the canonical org ID so Alex can verify against D&B lookup; prevents duplicate-record approvals

Data Model

  • Partner_Application__c: Company_Name__c, DUNS__c, Partner_Type__c, Region__c, Submitted_Date__c, Status__c, Days_In_Queue__c (formula), Tier_Recommendation__c, Risk_Flag__c, Assigned_PAM__c
  • Compliance_Checklist__c: Application__c, NDA_Status__c, W9_Status__c, Insurance_Status__c, Credit_Check_Status__c

Business Logic

  • SLA target: 30 days from submission. Days_In_Queue__c = TODAY() − Submitted_Date__c
  • Status = Overdue when Days_In_Queue__c > 30 and Status ≠ Approved/Rejected
  • SLA Warning fires at 20 days (≥ 2/3 of window elapsed)
  • Unassigned applications cannot progress past "New" status; PAM assignment is required
  • Tier recommendation auto-scores from: Equinix revenue history, partner type, region, certification level

Navigation

  • Row → pam-application-detail.html (full application review)
  • "Assign" button → inline assignment modal (no page nav)
  • "Bulk Assign" → selects rows and opens assignment fly-out
  • Related screens: pam-tier-dashboard.html, pam-partner-financial.html
