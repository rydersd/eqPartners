Design Specs

Summary

Federated search results showing deals, accounts, courses, resources, and commissions for name-based and account lookups, helping partners quickly locate pipeline information and training resources.

Jobs to Be Done

  • Find deals before registration
  • Locate deal status and approval progress
  • Search training courses by keyword
  • Access sales tools and marketing collateral
  • Check commission status and payment info
  • Navigate to records and relevant information quickly

Design Specification

Primary Content

  • Global search bar with query display
  • Results summary showing count and time
  • Object-type tabs
  • Federated results grouped by type with result cards
  • Recent searches for quick re-access
  • Faceted filter sidebar for refinement

Interactive Elements

  • Search input with clear button and suggestions
  • Switch between object type tabs
  • Click results to navigate to records
  • Apply filter checkboxes and radio buttons
  • Click recent searches to re-run query
  • Pagination for large result sets

Functionality

  • Multi-Object Search & Querying
    • Salesforce global search simultaneously queries Deal_Registration__c, Account, Course__c, ContentDocument (Knowledge), and Partner_Commission__c objects using a single SOSL query
    • Results deduplicated by object ID to prevent duplicate records in same result set
  • Result Organization & Display
    • Results grouped by object type with color-coded section labels (dealcode #6b7f99, account #3d6daa, courses #1e2a3a, resources #8b7745, commission #1e2a3a)
    • Result snippet text uses <mark> HTML elements with yellow background (#edf1f7) to highlight search term matches
    • Each result card displays icon, title, metadata, and contextual right-aligned info (amount, status, date)
  • Dynamic Filtering & Counts
    • Tab counts dynamically update based on search filters applied via sidebar (Object Type, Date Range, Deal Stage)
    • Faceted filters AND-combined and update result counts via AJAX without page reload, maintaining search context
  • Search History & Recent Access
    • Recent searches cached in browser localStorage with 5-item limit and cleared on explicit user action, enabling quick re-access of common queries
    • Recent searches sidebar appears above filters for fast navigation to frequently searched items
  • Accessibility & Navigation
    • Tab order follows logical flow: search input → results summary → tabs → sidebar filters → result cards, supporting keyboard navigation
