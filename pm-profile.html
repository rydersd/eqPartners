My Profile — Portal Admin

Trigger

This page is reached by clicking the user avatar in the top-right of the Partner Portal navigation bar. The admin avatar shows initials with the Portal Admin color (blue accent). An aria-current="page" attribute marks it as active when on this page.

Design Notes

  • Unlike the Sales Rep profile, the Admin profile shows the Permissions card instead of Certifications, since certifications are less central to the admin role
  • Admin role and permissions are managed by Equinix/PSM, not self-service — the section is read-only
  • SSO linking is only shown for organizations that have configured SSO via Equinix's identity broker
  • The Notification Preferences section will have more rows for admins than sales reps due to org-level events
  • Recent Activity for admins logs administrative actions (user management, MDF, reports) not just personal activity

Differences from Sales Rep Profile

Portal Admin profile swaps the Certifications card for an Admin Permissions card. The hero role tag uses blue (Portal Admin color) instead of violet (Sales Rep color). The activity log reflects admin actions rather than deal/training activity.
