Jobs to Be Done

  • Track all active certifications across organization
  • Proactively manage upcoming expirations
  • Ensure tier certification requirements are met
  • Support individual rep development planning
  • Generate compliance reports for Equinix

Design Specification

Primary Content

  • Certification tracker for all reps in organization
  • Cert matrix: rep name vs certification type with status badges
  • Expiration calendar view and 30/60/90-day grouping
  • Compliance summary KPIs: active certs, expiring soon, expired, team coverage %
  • Tier requirement mapping (Gold vs. Silver qualification thresholds)

Interactive Elements

  • Toggle between grid view and list view
  • Filter by certification type or status
  • Click cert cell to view detail
  • Bulk send renewal reminders (Nudge to Renew buttons)
  • Export cert matrix to Excel
  • View certification requirements by tier

Functionality

  • Data Integration
    • SumTotal/LMS API sync pulls certification status in real time
    • Nightly batch refresh with manual per-contact refresh option
  • Expiration Management
    • Scheduled flow flags certs entering 30/60/90-day expiration windows
    • Nudge button triggers email notification to individual team member
    • Visual status badges shift from Active → Expiring → Expired automatically
  • Compliance Calculation
    • Team coverage % derived from active Certification__c count vs. required count per tier
    • Gold/Silver tier thresholds evaluated against current cert portfolio in real time
  • Audit & Reporting
    • All certification actions logged to CertificationHistory__c with timestamp and actor
    • Export generates Excel matrix of rep × certification with status columns
