Design Specs

Summary

Post-signature confirmation page showing real-time countersign status while partners await Equinix execution and providing actionable next steps for team preparation.

Jobs to Be Done

  • Display real-time countersign status with automatic progress updates when agreement is countersigned
  • Provide downloadable partner-signed agreement copy for record-keeping
  • Show step indicator with 4 completed steps and 1 active pending step
  • Poll countersign status and auto-redirect to onboarding-welcome.html when fully executed
  • Provide clear escalation path and channel manager contact info

Design Specification

Primary Content

  • Success card confirming agreement signature receipt with agreement ID
  • Agreement processing status tracker showing 5-stage flow
  • Pending info banner indicating countersignature is in progress with 1-2 business day estimate
  • Auto-generated confirmation email mockup with system badge and greeting
  • Downloadable partner-signed agreement PDF with file details and size
  • While You Wait grid with 4 recommended activities during the countersign period
  • Channel Manager contact card with name, email, and call scheduling option

Interactive Elements

  • Status tracker with horizontal timeline and pulsing amber animation on current stage
  • Document download card with download action link
  • Email mockup with system toolbar and readable email layout with checklist items
  • Channel Manager contact links with email and phone options
  • Next steps grid with numbered items and descriptions

Functionality

  • Document Status Tracking & Auto-Routing
    • Polling mechanism checking Partner_Agreement__c.Countersign_Status__c field via client-side setInterval() function every 30 seconds making AJAX call to backend /api/agreement-status endpoint
    • Status comparison logic on page evaluating Countersign_Status__c value against 'Pending', 'Countersigned', 'Fully Executed' states from picklist
    • Auto-redirect to onboarding-welcome.html triggered by JavaScript window.location.href assignment when status transitions to 'Fully Executed'
  • Email & Notification Management
    • Server-side email log generating confirmation message via Salesforce Messaging.sendEmail() call storing email record in EmailMessage object linked to Partner__c
    • Email template using Salesforce template field merging with {!Partner_Agreement__c.Document_ID__c} and {!Partner__c.Name__c} dynamic values
    • Channel Manager notification email triggered via Process Builder when Agreement.Status__c = 'Partner Signed' workflow action
  • Document Generation & Download
    • PDF generation executing Salesforce Apex callout to DocuSign API fetching completed document package and returning signed envelope PDF bytes
    • PDF file creation storing document binary in Attachment object linked to Partner_Agreement__c with File_Type__c = 'Signed Agreement PDF'
    • Download link rendering dynamically from Attachment.Id referencing /servlet/servlet.FileDownload?file={!AttachmentId} URL pattern
  • Engagement & Self-Service
    • Activity recommendation carousel displaying curated training videos and onboarding resources via Lightning Web Component data iteration loop over Partner_Resource__c records
    • Internal linking in carousel items routing to partner-resource URLs stored in Partner_Resource__c.URL__c with UTM parameter tracking clicks to engagement metrics

Technical Details

Key Objects

  • Partner_Agreement__c (Status__c = 'Partner Signed', Countersign_Status__c = 'Pending')
  • EmailMessage — Auto-generated confirmation email from Equinix Legal
  • Partner__c — Linked account with Channel Manager lookup
