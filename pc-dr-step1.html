Design Notes

Summary

Step 1 of the Deal Registration wizard. Jordan Reeves enters basic prospect company information — name, country, website, DUNS number, and address. The registration type (Referral or Resale) selected on the prior screen is shown as a context chip in the hero. The right column is reserved for a future AI assistance panel.

Flow Position

  • Flow: Deal Registration wizard — Step 1 of 4
  • Previous: pc-dr-deal-type.html (relationship type selection)
  • Next: pc-dr-step2.html (Deal Details)

Design Decisions

  • No max-width constraint — full-width grid layout to accommodate a future AI assistance panel on the right
  • AI rail — sticky right column, 300px wide, placeholder state. Will surface contextual help, duplicate detection, and company autofill in a future release
  • Context chip — registration type (Referral/Resale) carried forward from deal-type screen and shown in the hero subtitle so the user never loses context mid-form
  • CNPJ conditional field — appears only when Brazil is selected as the country
  • DUNS lookup link — links to D&B lookup; autofill from DUNS is a planned AI assistant feature

Form Fields

  • Company Name — required, text
  • Country — required, dropdown
  • Company Website — optional, URL
  • DUNS Number — optional, 9-digit
  • CNPJ — conditional (shown for Brazil only), required if Brazil selected
  • Address Line 1 — required
  • Address Line 2 — optional
  • City/Town — required
  • State/Province — optional (required for US/Canada in validation)
  • Zip/Postal Code — required
