Design Specs

Summary

Displays all training courses in a sortable, filterable table view with real-time progress tracking. Partners can manage required and elective coursework while monitoring their overall certification readiness.

Jobs to Be Done

  • View all training courses in sortable table format
  • Quickly scan course details and progress
  • Compare courses by completion, difficulty, or date
  • Filter to focus on specific course types
  • Launch courses from table interface
  • Analyze training completion trends

Design Specification

Primary Content

  • Training progress summary with required/elective KPIs
  • Overall completion percentage and visual progress bar
  • Learning path timeline showing completion status of all modules
  • Multi-tab interface for Required, Elective, Completed, and Expired courses
  • Comprehensive course table with course title, ID, track, status, progress, duration, due date, score, and actions

Interactive Elements

  • View toggle between table, card, and kanban layouts
  • Tab switching to filter courses by status
  • Sort dropdown for course title, due date, or status
  • Search input to filter courses by keyword
  • Action links for Resume, Start Course, Re-enroll, View/Download Certificate
  • Inline progress bars for in-progress courses

Functionality

  • Tab-Based Filtering & Visibility
    • Tab switching (All/Required/Elective/Not Started/In Progress/Completed/Expired) toggles visibility of filtered tables without page reload using client-side JavaScript or CSS display toggles
    • Each tab applies WHERE clause filter on Partner_Training__c: Tab='Required' filters Is_Required__c=true, Tab='In Progress' filters Status__c='In Progress', etc.
    • Tab counts dynamically updated after sort, search, or status changes (e.g., "In Progress (3)" updates to "In Progress (2)" when one course completes)
  • Sorting & Search Operations
    • Sort dropdown reorders table by selected column (Course Title, Due Date, Status, Completion %); applies ASC or DESC ordering to Partner_Training__c SOQL query
    • Search input filters courses by keyword: SOQL WHERE Course.Name LIKE '%[keyword]%' OR Course.Description__c LIKE '%[keyword]%'; table updates dynamically without page reload
    • Sort and search persist in URL query parameters or session state for back-button navigation
  • Progress Calculations & Status Tracking
    • Progress calculations aggregate: Required % = (COUNT(Partner_Training__c WHERE Is_Required__c=true AND Status__c='Completed') / Tier_Course_Requirement__mdt.Required_Count) × 100, Elective % similarly calculated
    • Overall progress = (Completed_Count / Total_Enrolled_Count) × 100; capped at 100%
    • Course status transitions (Not Started → In Progress → Completed → Expired) automatically update action buttons: Start Course (Not Started), Resume (In Progress), Re-enroll (Expired), View Certificate (Completed)
  • Urgency & Overdue Detection
    • Due date comparison: IF Partner_Training__c.Due_Date__c < TODAY() AND Status__c='Not Started' THEN highlight row with Overdue badge (red styling)
    • Expired detection: IF Certification__c.Expiration_Date__c < TODAY() THEN move course to Expired tab and display "Expired" badge; prevent course start unless re-enrolled
    • Overdue courses sorted to top of table for visibility
  • Action Links & Enrollment Workflows
    • Start Course link creates Partner_Training__c enrollment if not exists; generates JWT SSO token and redirects to SumTotal LMS with Course.SumTotal_Course_ID__c
    • Resume link skips enrollment step (record already exists); redirects to LMS with Partner_Training__c.LMS_Module_Index__c to resume from last module
    • Re-enroll button creates new Partner_Training__c with Status='Not Started'; original expired record retained for audit trail
    • View/Download Certificate link available only when Partner_Training__c.Status='Completed'; fetches Certificate_PDF_URL__c and opens/downloads PDF
  • Progress Visualization & Updates
    • Inline progress bars displayed in table for In Progress courses; width = (LMS_Module_Index__c / Total_Modules) × 100
    • Learning path visual (left sidebar) updates in real-time when course status changes; completed courses marked with checkmarks, current course highlighted
    • Table rows highlight with background color when course status transitions (e.g., green highlight when course moved to Completed column)

Technical Details

Validation & Business Logic

  • Required courses must be completed before certification eligibility
  • Expired courses must be re-enrolled within 30 days
  • Progress cannot exceed 100%
  • Due date must be in future for active courses
