Design Notes

Summary

Three-panel messaging interface integrating Salesforce Experience Cloud messaging with Slack channel sync. Featured: Sarah Connor and Marcus Chen conversation about Security Fundamentals cert expiration and re-enrollment urgency for Stark Industries deal protection. Features conversation list, deal-specific team channels with auto-managed membership, message thread display, and contextual Agentforce AI assistance with commerce and deal intelligence.

Jobs to Be Done

  • Communicate with PSM and sales team about active deals in dedicated channels
  • Access deal-specific context without leaving the messaging interface
  • Receive AI-powered guidance on commission calculations and competitive positioning
  • Sync messages with native Slack for team members using Slack as primary tool
  • Search conversations and quickly jump to relevant discussions by deal or contact
  • Track engagement history and team activity on opportunities

Design Specification

Primary Content

  • 3-panel layout: Left sidebar (conversation list), Center (message thread), Right sidebar (Agentforce AI)
  • Conversation list with tabs (All, Direct Messages, Channels, unread badge counts)
  • Message items showing avatar, name, preview text, timestamp, unread indicator
  • Message types: personal contacts (circular avatar + name), deal channels (#deal-name with channel icon), Agentforce (special badge)
  • Search bar to filter conversations by name, deal, or contact
  • Thread header showing conversation title, channel tag, action buttons (View Deal, Open in Slack)
  • Message history with timestamps, user names, roles, and message content
  • Deal context card embedded in thread showing key metadata (Deal Name, Amount, Stage, Close Date, Commission Estimate)
  • Agentforce responses in thread with special styling (left blue border), label ("AI RECOMMENDATION"), source links
  • Compose bar at bottom with text input, attachment button, AI assist button, send button

Interactive Elements

  • Conversation list items clickable to open thread
  • Search input filters conversation list real-time
  • Tab filters (All, Direct, Channels)
  • View Deal button navigates to Opportunity detail page
  • Open in Slack button deep-links to Slack channel (if synced)
  • Message links (e.g., opportunity links) clickable within thread text
  • Compose bar send button to post new message
  • Attachment button to upload files
  • AI Assist button to trigger Agentforce suggestions
  • Agentforce suggestion chips (one-tap prompts for "Calculate Commission", "Competitive Intel", etc.)
  • Source links in agent responses navigate to referenced records

Functionality

  • Conversation Initialization & Channel Management
    • Conversation list populated from ConversationEntry__c (direct messages, MessageType__c='Direct') and Deal_Channel__c (deal channels, MessageType__c='Channel'); sorted by most recent message (CreatedDate DESC)
    • Deal channels auto-created via Flow trigger on Opportunity creation; channel name = Opportunity.Name; SlackChannelId__c auto-populated if Slack integration enabled
    • Channel membership automatically populated via Channel_Member__c junction: partner rep (role='Rep'), assigned PSM (role='PSM'), Account Executive from OpportunityTeam (role='AE'), Solutions Architect if applicable (role='SA')
  • Message Sync & Bi-Directional Integration
    • Message sync with Slack via Slack Integration API using OAuth tokens stored in Named Credentials; webhooks trigger synchronization on ConversationEntry create/update
    • Messages created in Salesforce ConversationEntry appear in linked Slack channel within seconds; Slack messages synced back via webhook with IsFromSlack__c=true flag
    • Slack direct message conversations mapped to ConversationEntry records with ParticipantUser__c relationships; encrypted at rest in Salesforce database
  • AI-Powered Agent Assistance
    • Agentforce agent deployed with read-only access to: Opportunity, Deal_Registration__c, Partner_Commission__c, Product2, PricebookEntry, Training_Assignment__c, Partner_Tier_Rates__mdt
    • Agent function definitions enable: getCommissionEstimate(opportunity_id) = SUM(Amount * Partner_Tier_Rate lookup), getCompetitivePricing(product_name, competitor), checkTierStatus(contact_id) = required certs vs. earned certs, getTierRequiredCourses(tier) list
    • Agentforce suggestion chips trigger pre-built prompts (e.g., "Calculate Commission", "Competitive Intel", "Tier Requirements"); agent responds with sourced information and relevant record links
  • Context & Search
    • Deal context card auto-populated from Opportunity via relationship: displays Name, Amount, StageName, CloseDate, EstimatedCommission__c; updates when Opportunity record changes
    • Message search powered by Salesforce Platform Search with indexed fields: ConversationEntry.Text__c, CreatedBy.Name, Deal_Channel__c.ChannelName__c; search results link to related conversations
  • Compose & Collaboration
    • Compose bar triggers ConversationEntry record creation with Text__c, MessageType__c, Thread__c (for threaded replies), CreatedBy (auto-set to current user)
    • Attachment button uploads files to Salesforce Files (ContentDocument); linked to ConversationEntry via ContentDocumentLink
    • Send button validates message text (non-empty) and submits; triggers Flow to sync message to Slack if IsFromSlack__c=false and Slack integration enabled

Technical Details

Salesforce & Integration Objects

  • ConversationEntry__c: Text__c, CreatedBy (lookup), Thread__c (self-lookup), MessageType__c (Direct|Channel), IsFromSlack__c (checkbox)
  • Deal_Channel__c: Opportunity__c (lookup), ChannelName__c, SlackChannelId__c (external ID), CreatedDate__c
  • Channel_Member__c: Deal_Channel__c, Contact__c or User__c (polymorphic), Role__c (Rep|PSM|AE|SA)
  • Slack Integration via Slack Kit SDK: OAuth token stored securely in Named Credential; webhooks trigger sync on message create/update in both directions
  • Agentforce agent deployed with function definitions for: getCommissionEstimate(), getCompetitivePricing(), checkTierStatus(), getTierRequiredCourses()
  • Message search powered by Salesforce Platform Search with indexed fields: ConversationEntry.Text__c, ConversationEntry.CreatedBy.Name, Deal_Channel__c.ChannelName__c
