Summary Card: When "commission" + a time period (Q1, Q2, 2026, etc.) is detected, a contextual summary card appears above results showing earned/paid/pending/pipeline commission for that period. This gives the rep their answer immediately without parsing individual results. Summary is built from a SOQL aggregate query on Partner_Commission__c filtered by Payment_Date__c or Earned_Date__c within the quarter.
Pipeline Commission: The "Related Deals — Q1 Closeable" section surfaces deals in the pipeline that could close within the searched quarter, with estimated commission calculated using the rep's current tier rate. This forward-looking view helps reps understand their potential earnings and prioritize deal progression.
Contextual Filters: Payment Status (Paid, Scheduled, Pending Approval) replaces standard object type filters. Quarter selector provides quick navigation between time periods. Partner Tier filter shows commission rate alongside tier name for transparency.
Accessibility: Summary card has role="region" with aria-label. Financial amounts use consistent formatting ($XX,XXX). Status badges use text + color (not color alone). All monetary values are right-aligned for scanability. Screen reader announces: "Commission: Acme Cloud Migration, forty-three thousand one hundred twenty-five dollars, status: paid."

Design Specs

Summary

Searchable commission explorer with contextual summary cards showing quarterly earnings broken down by earned, paid, and pending status. Partners can filter by quarter, tier, and payment status, explore commission calculations, and forecast pipeline earnings potential.

Jobs to Be Done

  • See quarterly commission totals at a glance
  • Check payment status and expected payout dates
  • Estimate earnings from pipeline deals
  • Access commission documentation and FAQs
  • Prioritize deals to maximize quarterly earnings
  • Forecast revenue and commission projections

Design Specification

Primary Content

  • Search input with natural language support for time periods (Q1, Q2, 2026, etc.)
  • Commission summary card showing earned, paid, pending, and pipeline totals for selected quarter
  • Commission records table with: Deal Name, Customer, Amount, Commission Earned, Payment Status, Expected Payout Date
  • Related Deals section showing pipeline deals with estimated commission using current tier rate
  • Filter bar with quarter selector, payment status filter, and partner tier filter
  • Commission documentation and policy reference section

Interactive Elements

  • Search input accepts natural language queries detecting quarters and years
  • Quarter radio button selector for quick period navigation
  • Payment Status filter chips: All, Paid, Scheduled, Pending Approval
  • Partner Tier dropdown showing tier name and commission rate
  • Commission record row click shows full transaction details
  • Deal row click displays commission calculation breakdown
  • Download button exports commission statement for selected quarter
  • Summary card sections collapse/expand to show detailed breakdowns

Functionality

  • Search & Filtering
    • Search input parses natural language to detect quarter/year references (Q1, Q2, 2026) using regex patterns
    • Payment status filter updates results without page reload by toggling visibility or querying SOQL
    • Partner Tier filter shows commission percentage alongside tier name retrieved from user's tier record
  • Data Aggregation & Calculation
    • Summary card aggregates Partner_Commission__c records by status using SOQL sum operations
    • Pipeline commission calculates estimated earnings from open deals using current user's tier rate
    • Quarter selector automatically calculates date range from selected period and refreshes data via API call
  • Display & Accessibility
    • Right-aligned monetary values for scannable presentation and easier visual parsing
    • Status badges use text plus color for accessibility and visual differentiation
    • Summary card sections collapse/expand to show detailed breakdowns without navigation
  • Navigation & Export
    • Record click navigates to detailed transaction view with full commission context
    • Export generates PDF or CSV statement for audit/documentation purposes via document generation service

Technical Details

Validation & Business Logic

  • Commission records queried from Partner_Commission__c filtered by Payment_Date__c or Earned_Date__c
  • Summary aggregation uses SOQL sum/count on status groups
  • Pipeline commission calculated using rep's current tier rate from OrgTier__c or equivalent
  • Payment date range validation ensures quarter boundaries are correct
  • Export document generation respects user's access permissions
