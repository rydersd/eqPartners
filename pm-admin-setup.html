Admin Setup Workflow · Design Notes

Purpose and placement

This wizard is the step-by-step guided companion to the Day 0 Dashboard summary card. It's linked from every "Continue setup" or "Open setup wizard" CTA on the Day 0 dashboard. The wizard opens at the current incomplete step (determined by the admin's Contact boolean fields). After all 4 steps are complete, Admin_GS_Complete__c flips to true and the user is redirected to the Day N dashboard.

EC implementation

The wizard is a Salesforce Screen Flow embedded as an EC component. Each step is a Screen within the Flow. Navigation (Back/Next) uses standard Flow navigation. Step state is read from Contact boolean fields at load time. On completion, a Flow invokes Apex to set Admin_GS_Complete__c = true and redirects to the dashboard via a Navigate action.

Step SF fields

  • Step 1: Admin_GS_Profile__c — set when Account profile fields pass completeness check
  • Step 2: Admin_GS_Requests__c — set when all open PartnerUserRequest__c records are resolved
  • Step 3: Admin_GS_Training__c — set when at least 1 course has Required__c = true
  • Step 4: Admin_GS_Backup__c — set when Account.Backup_Admin__c is populated
  • All done: Admin_GS_Complete__c — formula OR Apex trigger fires when all 4 are true

Accessibility

  • Stepper uses role="list" / role="listitem" with aria-label on each step
  • Tab row uses role="tablist" / role="tab" / aria-selected
  • Content panels use role="tabpanel" + aria-labelledby
  • Training toggles are <button> elements with aria-label and title
  • Backup admin list uses role="radiogroup" + role="radio" + aria-checked
  • Step indicators convey state via text label, not color alone
