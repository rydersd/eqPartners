Design Specs

Summary

S.H.I.E.L.D. Secure Connect Deal Review (DR-2026-4401) — $1.62M TCV with CloudBridge Solutions (Gold tier, 15% commission = $243K). Secure multi-region interconnection for classified data infrastructure. No conflicts detected, territory clear. Ready for PSM approval. Successful close qualifies Stark for Platinum tier advancement over $5M MRR threshold.

Jobs to Be Done

  • Review individual deal submission with full context and conflict analysis
  • Assess territory and pricing compliance before approval
  • Document approval decision and rationale for audit trail
  • Resolve deal conflicts with multiple resolution paths
  • Route deal to commission processing upon approval

Design Specification

Primary Content

  • Deal submission header with TechVision Partners, KPI cards
  • Deal Submission Details grid
  • Conflict Analysis card with confidence meter, Territory Verification checkmark
  • Activity Timeline showing 5 events
  • PSM Notes textarea for review comments and decision rationale

Interactive Elements

  • Approve/More Info/Reject action buttons in sidebar
  • Conflict resolution radio options
  • Notes textarea for approval decision documentation

Functionality

  • Data Retrieval & Display
    • Query Deal_Registration__c record with related partner account, customer account, and product details
    • Display partner tier (Gold, Silver, etc.) and associated commission rate from Partner_Account__c lookup
    • Render deal submission metadata including submission date, customer contact info, and product interest
  • Conflict Detection & Analysis
    • Perform AE bridge conflict detection by querying Opportunity records for overlapping account assignments
    • Calculate confidence score (0-100) based on territory history and prior engagement data
    • Display conflict alert with recommendation for documentation request or rejection path
  • Commission Calculations
    • Calculate expected commission using formula: deal value × partner tier rate percentage
    • Apply tiered discount thresholds (Gold partners up to 15%, Silver up to 10%, etc.)
    • Validate proposed discount against policy limits and display compliance status
  • Approval Workflow & Status Management
    • Log approval action with timestamp, PSM user ID, and notes to Deal_Registration__c record
    • Update Deal_Registration__c Status field to Approved/Rejected/Pending with rationale documentation
    • Set 90-day protection period by calculating expiration date and storing in Protection_End_Date__c field
  • Notifications & Integration
    • Trigger approval email notification to partner contact on submit using EmailAlert workflow action
    • Route approved deal to commission processing queue via Process Builder for invoicing system integration

Technical Details

Validation & Business Logic

  • Deal header (customer name, partner rep, amount, product, submission date)
  • Deal description and competitive information
  • Customer account lookup results (existing Equinix relationship check)
  • AE bridge conflict detection alert
  • Commission calculation preview (MRR × tier rate)
