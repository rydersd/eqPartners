Design Specs

Summary

Gives the PSM a financially grounded view of their partner portfolio — MRR totals, growth trends, tier distribution, and near-win spotlights. Training surfaces as a lightweight status signal (On Track / Needs Attention / Overdue) rather than the primary lens. Partners are always in scope; filtering narrows by tier, status, and period.

Jobs to Be Done

  • Understand portfolio MRR and quarter-over-quarter growth at a glance
  • Spot near-win partners within 15% of next tier to prioritize outreach
  • Identify at-risk accounts before revenue erodes
  • See training health as a signal without it dominating the view
  • Drill into regional and top-partner MRR breakdowns for planning
  • Export filtered portfolio data and schedule recurring reports

Design Specification

Primary Content

  • KPI strip: Total Partners, Portfolio MRR ($2.6M ↑8% QoQ), MRR Growth (+$190K QoQ), Near-Win Count, At-Risk Count — all with period-over-period trend indicators
  • Near-Win Spotlight: 6 partner cards showing account name, tier advancement gap (e.g., Silver → Gold: 8%), MRR, assigned PM, and last contact date with Encourage action
  • Program Analytics: Tier Distribution stacked bar (Gold/Silver/Bronze/Registered) + MRR Trend 6-month SVG line chart
  • Comparison charts: Top 5 Partners by MRR (horizontal bars) + MRR by Region (horizontal bars: US West / US East / EMEA / APAC)
  • Partner Portfolio table (12 rows, paginated): Account · Tier · Team Size · MRR · Training badge · Status · Regions · Last Activity · Actions
  • Sync status banner appears conditionally when data is stale (amber outline, no solid fill)

Interactive Elements

  • Search field for filtering table by account name
  • Filters button opens right-side filter panel (Salesforce Lightning pattern)
  • Active filters displayed as removable chip pills below toolbar (Tier, Status, Period)
  • Encourage button on each Near-Win card triggers encouragement modal
  • Account name links navigate to PSM Partner Account Record
  • Encourage / View action links in portfolio table rows
  • Refresh, Export CSV, and Schedule Report buttons in toolbar
  • Table column headers are sortable; default sort is MRR descending

Functionality

  • KPI Aggregation
    • Queries Partner_Scorecard__c aggregates per Account: Total Partners (COUNT), Portfolio MRR (SUM(MRR__c)), MRR Growth (SUM(MRR__c) vs prior quarter SUM), Near-Win Count (Near_Win__c = true), At-Risk Count (At_Risk__c = true)
    • Trend indicators compute period-over-period delta using Partner_Monthly_Snapshot__c rolling averages
  • Near-Win Spotlight Query
    • Surfaces accounts where Tier_Gap_Pct__c <= 15 AND Partner_Tier__c != 'Platinum'; sorted by gap ascending to show closest candidates first
    • Each card shows tier advancement gap %, current MRR, assigned PM, and last contact date from Activity history
  • MRR Analytics & Charting
    • MRR Trend queries Partner_Monthly_Snapshot__c grouped by month for 6-month rolling window; renders as SVG polyline with area fill
    • Top 5 by MRR: ORDER BY MRR__c DESC LIMIT 5 from Partner_Scorecard__c; drawn as relative-width HTML bars
    • MRR by Region: GROUP BY Account.Region__c with SUM(MRR__c); drawn as horizontal bars with accent color fill
  • Filter Panel & Active Filter Chips
    • Filters button opens Lightning-style right panel with Tier, Status, and Period controls; selections written back as SOQL WHERE conditions
    • Active selections render as removable chip pills below toolbar; removing a chip resets that filter dimension to All and re-queries
    • isPartner = true is always implicit — not exposed as a visible filter since PSMs only operate on partner accounts
  • Training Badge Logic
    • Training_Status__c formula field evaluates LMS sync data: On Track (no overdue certs), Needs Attention (1–2 expiring within 30 days), Overdue (any expired or 2+ overdue courses)
    • Badge renders inline in table cell; does not drive sort or primary rank — MRR is the default sort
  • Export & Scheduling
    • Export CSV generates Account, Tier, MRR, Training Status, Status, Regions columns from current filtered query
    • Schedule Report saves Report_Schedule__c and triggers Flow to email dashboard snapshot on selected cadence

Technical Details

Key Objects

  • Account — Partner account record (isPartner = true implicit scope)
  • Partner_Scorecard__c — MRR, tier, training status rollup per account
  • Partner_Monthly_Snapshot__c — historical MRR and metric snapshots for trend charts
  • Partner_Tier_History__c — audit trail of tier changes
  • Report_Schedule__c — recurring report delivery configuration

Validation & Business Logic

  • Near-Win threshold configurable via custom metadata (default: 15% gap to next tier)
  • Dashboard sync banner triggers when last Platform Event is > 4 hours old
  • At-Risk flag set when MRR declines > 10% QoQ or training status = Overdue for 30+ days
  • Regions column displays up to 3 region tags; full list visible on the Partner Account Record
  • Deal approval blocked if partner tier = Registered (Bronze minimum required)
