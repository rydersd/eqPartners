Design Specs

Summary

Commission management system for PSMs to calculate, review, approve, and batch-process partner commissions based on tier rates and order amounts. Stark Industries (Gold 15% rate) commissions calculated across S.H.I.E.L.D. Secure Connect ($45K MRR), Hammer Industries, Roxxon Energy, and other active deals. Provides workflow staging and comprehensive audit trails.

Jobs to Be Done

  • Calculate and track partner commissions based on tier rates and order amounts
  • Stage commissions through approval workflow before payout
  • Allow rate adjustments with documented justification
  • Batch process approved commissions for payment
  • Maintain comprehensive audit trail of all commission changes and approvals

Design Specification

Primary Content

  • Four KPI cards showing Total Pending, Total Ready for Payout, Monthly Variance, Approval Rate
  • Commission formula reference available via on-demand modal link
  • Three tabs: Pending Calculations, Ready for Payout, Processed
  • Commission calculation table with partner, order date, amount, rate, commission, and status columns
  • Status badges (Calculated, Approved, Ready, Processed)

Interactive Elements

  • Tab switching between Pending Calculations and Ready for Payout views
  • Approve & Mark Ready button to move commissions to payout stage
  • Process Payout button for batch processing ready commission groups
  • Filter controls by partner tier, date range, status
  • Edit Commission links to adjust calculations with audit trail modal
  • Export to Finance button for CSV export to accounting systems
  • View Audit Trail link to see all changes and approvals per commission

Functionality

  • Commission Calculation & Retrieval
    • Calculate commission using formula: Order_Amount__c * Partner_Tier__r.Commission_Rate__c
    • Apply tier-based commission rates from Partner_Tier_Rate__c object for each transaction
    • Query Commission_Staging__c records grouped by Status__c (Calculated, Approved, Ready)
  • Validation & Tier Rate Management
    • Auto-validate no negative commissions and all tier rates are current before processing
    • Enforce commission amounts must be >= 0 and <= 100% of order amount via validation rules
    • Verify partner tier is active and rates have not been superseded
  • Adjustment & Approval Workflow
    • Create Commission_Adjustment__c record when rate change submitted with Justification__c field
    • Enforce adjustment workflow requiring PSM approval before recalculation and status change
    • Track all changes via field history on Commission_Staging__c in audit log for compliance
  • Staging & Batch Payout Processing
    • Stage workflow routing: Calculated → Approved → Ready → Processed with status validation gates
    • Only allow Approved status commissions to be marked Ready for Payout via workflow rule
    • Batch Process Payout creates Payment_Batch__c with multiple Commission_Staging__c records
    • Limit batch payout to 500 commissions per batch for system performance protection

Technical Details

Validation & Business Logic

  • Commission amounts must be >= 0 and <= 100% of order amount
  • Only Approved status commissions can be marked Ready for Payout
  • Adjustments require PSM approval before recalculation
  • Batch payout limited to 500 commissions per batch (system performance)
  • Field history tracking enabled on Commission_Staging__c for audit compliance
