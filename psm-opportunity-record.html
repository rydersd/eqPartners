Jobs to Be Done

  • Partner Involvement card populated from OpportunityPartner junction + Deal_Registration__c custom object + Partner_Commission__c related data
  • Protection countdown calculated from Deal_Registration__c.Protection_End_Date__c — displays amber warning when under 30 days
  • Slack channel auto-created via Salesforce-Slack integration when OpportunityPartner record is created — channel name derived from deal name
  • Slack embed uses Salesforce Slack Kit (Canvas) to surface last 3 messages in real-time within the Lightning record page
  • Activity Timeline combines Task, Event, and EmailMessage related records with custom Feed Items for system events (stage changes, approvals)
  • Left rail replaces standard Lightning related-list tabs — implemented as a custom Lightning Record Page layout with stacked components in the left region
  • Partner contacts sourced from OpportunityContactRole where Contact.AccountId matches the partner account

Design Specification

Primary Content

  • 3-column Lightning record layout: left rail, center
  • Partner Involvement card at TOP of left rail
  • Customer Contacts card below partner card with OpportunityContactRole data
  • Products/Line Items card showing OpportunityLineItem records with product name
  • Slack deal channel embedded in right rail showing recent messages with "Conti...
  • Activity Timeline in center showing automated events and logged calls

Interactive Elements

  • Open in Slack button in record header
  • Stage path bar with clickable stages for stage advancement
  • Edit button on detail card toggles inline editing on all fields
  • Log a Call / New Task / New Event quick actions on activity timeline
  • Partner contact "Profile" links navigate to the partner Contact record
  • Related list "View All" / "Add" actions open standard Lightning modals
  • Slack embed messages are clickable — opens the specific thread in Slack

Functionality

  • Opportunity & Partner Relationship Retrieval
    • Fetch Opportunity record with OpportunityPartner junction object to display all partner involvement and roles
    • Query Account (partner) records linked through OpportunityPartner and display partner tier, health score
    • Render opportunity details: name, amount, close date, stage, and related customer/partner accounts
  • Deal Registration & Protection Tracking
    • Query Deal_Registration__c linked to this Opportunity to retrieve protection end date and commission percentage
    • Calculate days remaining until protection expiration as (Protection_End_Date__c - TODAY())
    • Display protection countdown timer with amber alert if < 30 days remaining to renewal deadline
  • Slack Channel Management & Integration
    • Auto-create Slack channel when OpportunityPartner record created using Slack API integration
    • Embed recent Slack messages via Slack Kit to provide real-time collaboration context
    • Link channel name to Slack thread for easy navigation to full conversation history
  • Activity Timeline & Communication History
    • Aggregate Task records assigned to Opportunity or linked Account for action tracking
    • Query Event records where Opportunity is WhoId to display meetings and scheduled interactions
    • Retrieve EmailMessage records related to Opportunity contacts and log in activity feed
    • Display custom FeedItem__c records for PSM notes, deal updates, and milestone markers on timeline
  • Commission & Deal Status Calculations
    • Calculate expected commission from Deal_Registration__c using formula: Opportunity Amount × Partner Tier Rate %
    • Display deal protection status and determine if opportunity is covered under active protection period
    • Show commission calculation breakdown for transparency and deal approval documentation
