Job to Be Done

"When a partner registers a deal, I want to co-sell alongside them — providing Equinix technical resources, deal support, and executive access — so the deal closes faster and Equinix gets accurate attribution."

Key Design Decisions

  • Stage bar at the top — Marcus's deal conversations with partners always start with "where are we?" The visual pipeline stage answer that before anything else is said
  • Split next steps: Equinix vs. Partner — co-sell fails when action ownership is unclear; showing Equinix actions and partner actions separately forces accountability
  • Co-sell resources table — SAs, Deal Desk, and Executive Sponsor each have a status; Marcus needs to know if resources he requested are actually engaged
  • Activity feed — shared log between Marcus and Steve Rogers; both parties can see what's been done so no "I thought you were handling it" gaps
  • Attribution locked on registration — shows "Partner-Sourced (100%)" prominently because attribution disputes start when this isn't clearly documented
