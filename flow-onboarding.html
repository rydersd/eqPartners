Partner Org
Select Partner Type Discovers program via equinix.com or AE/partner referral. Selects type: SI, Reseller, ISV, or Referral.
4-Step Apply Wizard D&B company lookup → contact setup → partner type → legal attestation. Search-before-create prevents duplicates.
Awaiting PSM Decision Receives PCP-CONFIRM confirmation email. Status tracker shows "Under Review." No action required.
Sign Program Agreement Receives DocuSign link via email. Reviews and e-signs partner program agreement.
Status Tracker Monitors countersign progress. Receives PCP-AGRMNT email once fully executed.
Welcome & Credentials Receives PCP-WELCOME email with portal login link, temporary credentials, and PSM contact details.
6-Step Setup Wizard Profile, team member invites, competency selections, required doc uploads, and checklist completion.
Equinix PSM
Review Application 48h SLA Validates revenue fit, segment alignment, existing partner conflicts. Approves or declines in SF.
Generate Agreement Selects agreement template in SF, confirms terms and tier classification, initiates DocuSign envelope.
Countersign 1-2 day SLA Reviews executed partner signature, countersigns in DocuSign to fully execute agreement.
Activate & Assign Activates portal access, confirms PSM assignment in Partner_Account__c, schedules kickoff call.
Monitor Checklist Tracks onboarding wizard completion % in SF dashboard. Follows up on overdue items. Plans first QBR.
Salesforce
Create Application Record auto Provisions Partner_Application__c with D&B-matched company data, contact info, and partner type.
Route to PSM Queue auto Assigns to regional PSM queue. Triggers Marketing Cloud to send PCP-CONFIRM email to applicant.
Create Agreement Record auto Provisions Partner_Agreement__c. Sends DocuSign envelope via SF DocuSign package integration.
Monitor E-Sign auto Polls DocuSign status. Auto-sends reminder emails at 7, 11, and 13 days if unsigned.
Provision Account auto Creates Partner_Account__c, Onboarding_Checklist__c. Sets status to Active. Triggers PCP-WELCOME.
Track Progress auto Updates checklist completion %, tier eligibility clock starts, enables deal registration object access.
External Systems
D&B Optimizer auto Validates company name against D&B database; returns canonical DUNS record for dedup and data quality.
Marketing Cloud auto Delivers PCP-CONFIRM transactional email with application reference ID and expected timeline.
DocuSign auto Receives envelope from SF, delivers signing link to partner contact, stores executed PDF.
DocuSign → SF Webhook async Webhook fires on partner signature → SF updates Agreement status. Marketing Cloud sends PCP-AGRMNT.
Marketing Cloud auto Delivers PCP-WELCOME email with portal URL, temporary credentials, and PSM contact info.
Dashed border = partner is waiting, no action required auto = Salesforce or Marketing Cloud automation SLA = committed response time async = webhook / background process ← All Flows Reference
