Design Specs

Summary

Multi-step deal registration wizard guiding partners through submitting new opportunities for protection and approval. Sarah Connor (Stark Industries) registering AIM Technologies Edge deal ($12K MRR, Submitted status, DR-2026-4455). Features inline duplicate detection, real-time commission estimation, draft saving, and comprehensive deal context capture to streamline the registration process.

Jobs to Be Done

  • Register deals with duplicate prevention checks
  • Calculate commission earnings based on deal details
  • Save work in progress as draft for later completion
  • Submit deals for approval and protection period tracking
  • Understand commission structure and rate tiers
  • Track deal registration workflow and approval status

Design Specification

Primary Content

  • Page header with deal registration title
  • Four-step wizard with progress bar: Deal Basics → Deal Details → Commission & Competitive Intel → Review & Submit
  • Deal search/lookup panel with account autocomplete
  • Step 1: Customer name, product category, deal amount, expected close date fields
  • Step 2: Detailed customer information, competitive landscape, solution description
  • Step 3: Commission calculator showing estimated earnings by tier, deal structure info
  • Step 4: Summary review page with all entered details and edit shortcuts
  • Draft deals management section showing previously saved registrations

Interactive Elements

  • Account search input with autocomplete against Salesforce accounts
  • Next/Previous buttons for wizard navigation
  • Save Draft button available on all steps
  • Submit for Approval button on final review page
  • Form field validation with real-time feedback on blur
  • Commission calculation dynamically updates as deal amount changes
  • Duplicate detection warning highlighting overlapping deals
  • Edit links on review page jumping back to specific form sections
  • Draft deals card showing restore and delete actions

Functionality

  • Form Validation & Step Navigation
    • Wizard step validation prevents advancing without completing required fields using client-side checks
    • Deal amount validation ensures value is positive number using numeric constraints
    • Expected close date must be in future using date comparison logic
    • Form preserves step data in session/localStorage during wizard flow for persistence
  • Account & Duplicate Checking
    • Account lookup queries Salesforce accounts in real-time and filters results by search text using SOQL
    • Duplicate detection compares against existing Deal_Registration__c records with overlapping date ranges within 30 days
  • Commission & Protection Period Calculation
    • Commission calculation applies current user tier rate to deal amount retrieved from OrgTier__c field
    • Protection period automatically calculated as 30 days from submission date and displayed to user
  • Record Persistence & Workflow
    • Save Draft creates record with status "Draft" allowing later continuation and editing
    • Submit for Approval creates record with status "Pending Approval" and triggers approval workflow notification

Technical Details

Validation & Business Logic

  • Deal registration persisted as Deal_Registration__c custom object record
  • Duplicate check queries existing registrations with overlapping date ranges
  • Commission rate retrieved from user tier via OrgTier__c or similar field
  • Protection period calculated as 30 days from submission date
  • Required field validation enforced before step progression
